# 05 · 叙事配方与生产适配

本层把「怎样播放一个动效」扩展为「观众要理解什么、镜头怎样组织、为什么这样接」。实现继续使用现有帧驱动运行时，不新增电影 DSL 或自动导演系统。

## 一、四种对象

| 对象 | 定义 | 例子 |
|---|---|---|
| 内容场景 | 承载内容的类型 | 文字、卡片、界面、图表 |
| 叙事场景 | 围绕一个表达目标组织的一段内容 | 证明筛选能减少查找成本 |
| 镜头 | 一段连续的观看视角，可包含多个动作节拍 | 全局界面逐渐聚焦结果 |
| 镜头组合 / 叙事配方 | 可复用的表达步骤，可含一个或多个镜头 | 建立 → 操作 → 响应 → 结果 → 确认 |

动画状态变化不自动等于切镜，一个叙事场景也不限制为一个镜头。

## 二、配方数据合同

配方语义位于 `data/compositions.json`；可替换业务内容与最小镜头计划位于 `data/composition-scenes.json`。两者通过组合 id 绑定，校验器会拒绝缺失或孤立的计划。每个配方必须包含：

- `purposeId`、`goal`、`audienceTakeaway`：表达目的与观众理解；
- `contentTypes`、`formats`、`conditions`：素材前提、适用画幅和不适用条件；
- `attention`：主体、重点区域、景别、视野变化和上下文保留；
- `beats`、`tracks`、`keyframes`：动作节拍、运行时间轨和 2–6 个代表时刻；
- `continuity`：入口、出口、镜头关系、首选接缝和应保持的身份线索；
- `evidence`、`failureExample`、`capability`：依据、实现近似、失败例和验证状态。

每个镜头计划还必须说明 `sceneType`、`coverageStrategy`、是否切镜，以及每个镜头的主体、景别、视窗运动、内容运动和入口/出口状态。中文制作指令与导出 JSON 会同时包含配方、已解析内容和镜头计划。

## 三、首批六个配方

| 表达目的 | 配方 | 关键约束 |
|---|---|---|
| 主张与证据 | 标题 → 产品 → 证据重点 | 产品画面必须提供能核对标题的证据 |
| 操作与结果 | 输入 → 响应 → 结果 | 输入完成后先有系统响应，再出现独立结果对象 |
| 重点与上下文 | 全局 → 局部 → 回归上下文 | 特写绑定明确区域；返回后保留定位线索 |
| 状态变化 | 旧态 → 变化 → 新态 | 前后必须能识别为同一对象 |
| 前后比较 | 前后对比 → 差异确认 | 布局、尺度、视角和数据口径一致 |
| 层级导航 | 总览 → 选择 → 详情 | 选中状态先成立，详情保持名称、颜色和标识 |

工作台默认停在每个配方的代表帧，并提供 2–6 个代表时刻。当前六个示例均是一镜内完成，页面会明确展示覆盖策略和镜头角色，避免把每个节拍误解成一次切镜。

## 四、镜头术语与实现边界

- 景别与运动分开记录。特写可以静止，推进也不自动等于特写。
- HTML 的整体缩放标记为「二维取景近似」，不宣称产生真实机位移动的透视变化。
- 视窗横移与摄影机摇摄分开表达。
- 剪辑关系与视觉转场效果分开记录。匹配剪辑不要求 SVG Morph。
- 普通切镜允许直接切换，不要求前后对象坐标完全一致；只有连续变换才检查位置、尺寸和方向连续。

## 五、选型和衔接顺序

Agent 按以下顺序选择：

```text
表达目标 → 素材与状态条件 → 配方候选 → 前后衔接 → 动效参数
```

接缝先判断关系：

| 关系 | 首选处理 |
|---|---|
| 同一操作继续 | 保持输入和状态连续，响应后进入结果 |
| 同一对象换景别 | 保持对象身份、重点区域和定位线索 |
| 展示可比结果 | 保持布局、尺度、视角和数据口径一致 |
| 话题改变 | 直接切换；需要分段时再加字卡或明显转场 |
| 图形呼应 | 可做匹配剪辑，但不把呼应伪装成产品因果 |

## 六、通用与项目预设

通用工作台默认使用 1920×1080、24fps、`landscape-stage` 和通用业务内容。`opportunity-ai-vertical` 是独立项目预设：1080×1920、30fps、`portrait-stack`，并使用投资助手内容配置。切换预设不改配方和镜头语义。

## 七、生产合同与能力状态

运行时提供 `renderFrame(frame)` / `seekFrame(frame)`；同一帧不依赖前一帧历史。生产输入包含 `frame`、`fps`、`width`、`height`、`params`、`assets`。远程或加载失败的生产素材会阻止播放。

能力状态按以下顺序升级：

```text
browser-demo → production-adapted → production-verified
```

当前六个配方均为 `production-adapted`。浏览器预览、随机定位和构建已验证；尚未完成实际 MP4 输出与跨产品观众理解实验，因此没有配方标记为 `production-verified`。

## 八、Shader 边界

`ambient-gradient` 只负责单画面背景；`wipe` / `dissolve` 负责双画面转场，必须提供前后输入。普通遮罩、渐变和扫描线继续优先使用 DOM/SVG/CSS。
