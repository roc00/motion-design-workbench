# 03 · 提示词与制作配置

## 一、提示词公式

原词典给的公式，本质是「四层齐全」的简写：

```
操作对象 + 触发方式 + 动效名称 + 结束/替代状态
```

补上场景、技术工具与 UX 规则后，完整的一条是：

```text
在什么场景下（场景）→ 用项目现有工具（第一层）
谁触发（第二层）→ 什么条件下开始
画面怎么变（第三层）→ 动效名称 + 具体参数
怎样结束 / 怎样恢复（第三层）
要照顾哪些用户（第四层）→ 触屏替代、键盘焦点、减少动态
```

### 四层齐全的完整示例

> 使用项目现有的动画工具实现商品详情交互。
>
> 用户点击商品卡片时，用**共享元素转场**把卡片主图连续放大到详情页；返回时按原路径恢复。加入购物车后，按钮先显示短暂**加载**，再变成**成功对勾**，同时从页面底部出现「已加入购物车」的**轻提示**。
>
> 弹窗和抽屉打开后要锁定背景滚动，并正确移动**键盘焦点**。手机端把悬停操作改为点击；用户开启**减少动态**时，取消大幅位移和缩放，改用短促淡入淡出。

## 二、按场景生成提示词

`data/scenarios.json` 每个场景都带 `promptTemplate`，填空即可。每个条目自带的 `prompt` 可直接替换模板里的 `{表现细节}`。

**文字展示**

```text
{触发时机}，主标题使用{动效名称}（{English name}）。{表现细节}。
正文字号保持稳定清晰，不要逐字播放；整段动效在 {时长} 内完成，
字形与排版不要交给生成模型。
```

**背景转场**

```text
{触发时机}，使用{动效名称}（{English name}）完成两个画面之间的过渡。{表现细节}。
转场本体控制在 {时长} 内，为前后镜头各留 {handles} 帧 handles；
字体、Logo、数据等元素单独走确定性层合成，不要让转场吃掉它们的清晰度。
```

**卡片展示**

```text
{触发时机}，{数量}张卡片使用{动效名称}（{English name}）依次进入，
按从左到右、从上到下的阅读顺序。{表现细节}。
相邻卡片间隔 {交错间隔}，整组像一次连续动作；
卡片上的文字与数字保持清晰稳定，不参与缩放或倾斜。
```

**手机产品演示**

```text
{触发时机}，手机端使用{动效名称}（{English name}）。{表现细节}。
设备内屏比例与输出画幅分开设置；所有悬停操作改为点击 / 轻触；
保留可见的返回与切换按钮，不依赖手势。
```

**图表数据叙事**

```text
{触发时机}，使用{动效名称}（{English name}）呈现这组数据。{表现细节}。
标题写明结论，标注单位与时间范围；图元用不超调插值增长，
动画结束后停留展示准确终值，不循环、不回弹。
```

## 三、写提示词的顺序检查表

```text
谁触发 → 在什么条件下开始 → 触发后用什么动效 → 结束/离开后怎样恢复 → 键盘和触屏怎样替代
```

最常见的三种漏写：

| 漏写 | 后果 | 补法 |
|---|---|---|
| 没说按行 / 按词 / 按字符 | AI 自己挑，通常挑最花的那个 | 明写粒度 |
| 没说结束状态 | 动画播完就卡住，或莫名其妙循环 | 明写「播放一次后保持」「移开后回正」 |
| 没说触屏替代 | 手机上功能直接不存在 | 明写「手机端改为点击展开」 |

## 四、两种交付格式

界面上有两个固定的复制入口，内容都由**同一份已解析配置**生成（默认值 ⊕ `presets.json` ⊕ 项目预设 ⊕ 你在界面上的改动），所以改文案、改数值、改时长或画幅后，预览与两份复制结果同步。`staggerMs` 固定表示相邻元素的开始间隔，整组跨度另存为 `staggerSpanMs`。

### 制作指令（中文）

给做片子的人或 Agent 直接看。示例（实际复制所得）：

```text
【瀑布归因（Waterfall）· 效果】场景：图表数据叙事。
画布 1920×1080（16:9）、24fps；动作 5000ms（120 帧）、停留 1000ms（24 帧）；
可见镜头共 144 帧，前后各留 12 帧 handles（单列，不计入可见时长）。
结束状态：停在准确终值并保留阅读停留，不循环、不回弹。
实现：推荐渲染层 deterministic；当前示例能力为浏览器内可定位演示。
约束：图元用不超调插值；结束必须停在准确值，不循环、不回弹。
提示词参考：瀑布归因，5000ms 动作 + 1000ms 停留，结束停在终态不回弹。
```

### 镜头配置（JSON）

结构化交付物，保留 ShotSpec 的字段形状。示例（节选，实际复制所得）：

```jsonc
{
  "schemaVersion": "0.5.0",
  "configLabel": "制作配置",
  "effect": { "id": "component.toast", "zh": "轻提示消息", "nature": "effect" },
  "scenario": { "id": "screen", "name": "手机产品演示" },
  "canvas": { "width": 1920, "height": 1080, "fps": 24, "format": "16:9", "layoutPreset": "landscape-stage", "profileId": null, "colorSpace": "rec709" },
  "timeline": {
    "actionMs": 260, "staggerMs": 0, "staggerMode": "between-item-starts", "staggerCount": 1,
    "staggerSpanMs": 0, "actionSpanMs": 260, "holdMs": 1700, "exitMs": 300,
    "actionFrames": 6, "staggerFrames": 0, "holdFrames": 41, "exitFrames": 7,
    "totalMs": 2260, "visibleFrames": 54,
    "handlesInFrames": 12, "handlesOutFrames": 12,
    "note": "handles 单列，不计入可见镜头时长；总帧数由实际时间轴计算。"
  },
  "endState": "动画播放一次停在终态并保持；用户可重播。",
  "content": { "url": "https://motion.kit/share/abc", "message": "已复制到剪贴板" },
  "device": { "innerWidth": 393, "innerHeight": 852, "frame": "neutral" },
  "renderLayerRecommend": "deterministic",
  "exampleCapability": {
    "status": "browser-demo",
    "type": "frame-addressable-browser-runtime",
    "seekable": true,
    "reducedMotion": "static-terminal-or-short-fade",
    "notes": "保留 ShotSpec 的字段形状；不声称已完成 HyperFrames 或 Remotion 适配。"
  },

```

**两个字段必须分开看**：`renderLayerRecommend` 是这套体系对该条目的推荐渲染层；`exampleCapability.status` 描述当前实现处于 `browser-demo`、`production-adapted` 还是 `production-verified`。写了 `deterministic` 只是推荐；只有实际渲染路径通过后，才能标记为生产已验证。

## 五、给 Agent 的调用方式

不要让 Agent 自己从几十个条目里挑。按这个顺序喂：

1. **定场景**：告诉它这段是什么场景。
2. **给候选**：从 `effects.json` 里筛该场景 `core` 与 `good` 且 `nature: effect` 的条目。
3. **给约束**：把该场景 `notes` 里对应的那几条一并给出。
4. **给字段**：每个候选给出 `zh` / `en` / `core` / `prompt` / `presets[id].timeline` / `render` / `shotRoles`。
5. **要它输出**：`{ effectId, 理由, 参数, 镜头配置片段 }`，而不是只给一个动效名字。

一条可以直接用的指令：

```text
这是「卡片展示」场景。下面是该场景可用的动效候选（含时间安排与提示词示例）。
从中选一个作为主动作，说明理由，并按镜头配置格式给出这个镜头的参数。
不要选择候选之外的动效；如果都不合适，说明缺什么。
```

也可以直接读构建产物 `public/registry.json`（带 `schemaVersion`），里面有场景、条目、预设、镜头预设与图表数据。

## 六、常见失败模式

| 失败模式 | 根因 | 处理 |
|---|---|---|
| 所有元素同节奏淡入 | 提示词只给了动效名称，没给粒度与顺序 | 补触发方式 + 交错间隔 + 明确不要逐字 |
| 预览和成片不一致 | 断行、字体度量、容器宽度由实现层自由决定 | 把断行与尺寸写进配置；演示与成片共用同一份 preset |
| 改一个数字要重渲整片 | 数字被放进了生成层，或镜头没有独立可算 | 数字强制走确定性层；镜头按 shot 切分 |
| 手机上功能不见了 | 提示词只描述了 Hover | 每条 Hover 都要求给出非悬停的等价入口 |
| 图表读数被怀疑造假 | 图元超调、每帧自动缩放、缺失值补零 | 用不超调插值；固定全时段尺度；缺失断开 |
| 动画播完卡住或莫名循环 | 没写结束状态 | 配置里的 `endState` 必须交代清楚 |
