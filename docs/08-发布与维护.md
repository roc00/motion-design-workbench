## 项目内容

## 本地维护

1. 在项目根目录修改，使用 npm ci、npm run check、npm run skill:build 验证。
2. 本地公开仓库工作副本为 .publication/github；当前网站源副本为 .publication/site。同步当前内容后，在公开工作副本提交并推送 GitHub。
3. Sites 的项目身份保存在 .openai/hosting.json，继续使用已有 project_id。将新 dist 输出同步到网站源副本，使用 Sites source helper 提交、推送、打包，再保存版本与部署。
4. Sites 的访问范围为 public。临时源码写入凭据仅通过 helper 的隐藏 stdin 传入，不能写入文件、Git 配置或命令行参数。
5. 根地址无 hash 时进入完整词典；已有 #/compositions、#/effect/*、#/sequences/* 等链接继续可用。

本地原有 Git 仓库和历史保持原状，公开工作副本具有独立发布历史。线上版本使用 dist 静态文件，不需要访问 localhost 或本机文件。
