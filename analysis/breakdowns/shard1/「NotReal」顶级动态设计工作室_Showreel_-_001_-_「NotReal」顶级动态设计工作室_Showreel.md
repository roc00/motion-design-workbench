# 「NotReal」顶级动态设计工作室 Showreel.mp4

## 基础信息
- 类型：顶级动态设计工作室 Showreel（多客户作品集拼贴：微软 Phone Link / Designer、RingCentral、eBay 奢侈品、Camdez 家具等）
- 风格：电影级 3D + 扁平 MG 混合，高饱和色彩，快切蒙太奇
- 适用场景：设计/动效公司作品集、品牌混剪、多段商业片段的合集
- 时长 / 大致镜头数：494s，cuts 175，约 150+ 个镜头，平均 2–3s 一镜，属快切蒙太奇；内部穿插多段无缝长运镜

## 镜头结构
0–33s 是开场抽象品牌段（粉色流体、鸡尾酒台、椅子、隧道穿越、NotReal 标志）；36–117s 是微软 Phone Link  campaign（桌面+手机+UI 粉紫色调）；120–144s 是微软 Designer 烘焙 campaign（粉紫厨房、缎带）；148–200s 是 3D 环形/螺旋形状与 UI；204–285s 是 RingCentral 协作 campaign（蓝橙配色）；288–343s 是产品/周边平铺陈列（水杯、耳机、礼盒）；345–381s 是 Camdez 家具（kinetic type + 椅子）；384–393s 是 Klipsan 运动；396–417s 是蜡烛/Fluid Engine；420–477s 是 eBay 奢侈品字母 A–Z；480–492s 是平衡物体链式收尾。整片片是"客户片段串联"，每段自成一体，靠统一的 3D 渲染质感和快切节奏缝合。

## 动势
- 28.7→31.5 隧道穿越：Movement Z 轴持续加速；Timing ramp-up；Easing 加速；Feeling Cinematic
- 119.5→122.0 画笔→缎带：Movement 笔画→流动；Timing Slow；Easing ease-in-out；Feeling Premium
- 444→451 字母序列：Movement 硬切节奏；Easing 硬切；Feeling Editorial

## 空间与布局
作为合集，每个客户片段有自己的调色板与空间语言，但共享"3D 渲染 + 字卡叠层"的手法。最具电影感的是三段无缝长运镜：开场隧道穿越（平面字卡→三维隧道→产品）、Designer 缎带（Logo 笔画→流带→卡片→实物书）、eBay 字母（硬切但靠字母母题统一）。其余多为节奏硬切。

## 可沉淀的 Pattern 候选
- `wireframe-vanishing-point-tunnel`：平面装饰字卡向透视消失点收缩，线框旋成隧道，镜头穿越后在新场景中心"挤出"产品（28.7–32s，加密段1确认）。解决"从平面标题段进入产品展示"的电影化衔接，是本片最具复用价值的 Pattern。
- `logo-stroke-to-ribbon-card-to-object`：品牌笔画自绘→抹成流动缎带→缎带托出 UI 卡片→卡片放大成实体物件（119.5–125s，加密段2确认）。解决"品牌 Logo 如何自然过渡到产品 UI 再到实物场景"，缎带是贯穿载体。
- `outline-letter-product-alphabet`：每个产品镜头上叠加一个大号细轮廓字母，镜头间硬切但字母母题贯穿整段（444–451s，加密段3确认）。解决"一组同系列产品如何靠硬切串成有叙事感的序列"，字母本身即提纲。
- `object-balance-rube-end`：物件依次堆叠平衡作为片尾（480–492s）。灵感参考，Rube Goldberg 链条可程序化但物理感强。
- 注：写实 3D 产品渲染、奢侈品摄影、人物出镜属资产，机制层可程序化。
