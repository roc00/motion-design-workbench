# 请接收你的动画致幻剂～～ - 动态图形设计motion.mp4

## 基础信息
- 类型：动态设计工作室 Showreel / 机构宣传片（Blink*）
- 风格：高能量蒙太奇，粉彩渐变 + 3D 立体字 + 彩虹光晕，复古未来感
- 适用场景：设计机构、广告公司、创意团队的自我介绍与能力展示
- 时长 / 大致镜头数：39.8s，cuts 4（4.2、24.6、28.7、37.2），约 12–15 个段落，内部多为无缝连续运镜

## 镜头结构
开场一根发光黑柱在暗场亮起，随即炸成粉彩几何爆炸，"Blink*" 落版；中段用一条贯穿的隧道式 Z 轴穿越运镜把"FLEXIBLE / FAST RESULTS / 100% CUSTOM"等口号串成一面字墙；接着用奖杯、皇冠等道具把"26X Behance / 5X 设计奖 / 446M 曝光"等数据卡堆成陈列；再用"WHAT DO WE DO?"引出四类业务缩略图墙；最后白场淡出、CTA 文字打字、黑场 Logo 收尾。整体是"品牌爆点→口号隧道→数据陈列→业务清单→CTA"的机构片结构。

## 动势
- 0→3.9 柱→爆炸：Movement 中心向外膨胀；Timing Fast Start；Easing ease-out；Feeling Dynamic
- 10.4→15.6 隧道穿越：Movement Z 轴持续推进；Timing constant；Easing 线性；Feeling Cinematic
- 31.2→36.4 CTA 打字：Movement 垂直换行；Timing Slow Reveal；Easing 线性；Feeling Playful

## 空间与布局
全片靠"粉彩渐变 + 彩虹光晕"做 bg-continuity，隧道段是唯一的强纵深运镜，其余多为平面陈列。信息层级：品牌爆点（大字）→ 口号（隧道字墙）→ 数据（道具陈列）→ 业务（缩略图网格）→ CTA（小字），字号随层级递减。

## 可沉淀的 Pattern 候选
- `glow-bloom-brand-burst`：暗场单发光体过曝膨胀成全屏品牌爆炸（0–4s）。解决机构片开场爆点，比直接 logo fade 更有能量。
- `tunnel-word-wall-flight`：镜头沿 Z 轴穿越一排 3D 字墙，多句口号在一次连续运镜中飞过（10–15.6s）。解决"多个卖点口号如何不硬切地串起来"，是本段最值得复用的电影化衔接。
- `prop-reused-data-grid`：同组陈列道具（奖杯/皇冠）在多张数据卡间复用（16.9–22.1s）。解决"一组数据如何看起来成套"。
- `fade-white-type-campaign`：过曝白场后用打字机小字出 CTA（29.9–36.4s）。解决高能量片收束到冷静 CTA 的落差。
- 注：写实头像、皇冠奖杯造型属三维渲染资产，纯实现机制可程序化。
