# 每日品牌 - 一款产品品牌宣传 - Make something wonderful.mp4

## 基础信息
- 类型：品牌升级片 / 设计系统揭示（Excited! 品牌）
- 风格：极客风设计工具美学 —— 黑底 + 红/青/黄三色 + 贝塞尔手柄/网格/色板 UI 隐喻；Technical/Premium
- 适用场景：设计工具/品牌升级片、官网 hero 开场、品牌 rebrand announcement
- 时长 79.7s / 大致镜头数：cuts 30（4.0–4.9、22.9–31.9、46.5、67.2–70.0 三个密集快切段），约 25 段

## 镜头结构
0–5s 黑底 "New look, same excitement" 打字，绿箭头 logo 出现；9–18s 用 Figma 式操作从矩形画起、圆角、变八角星、贝塞尔线画六边形、选色板，把 brand mark 从原始图形"做出来"；21–32s 把"Excited!" 大字用贝塞尔 construction guides 逐字构造，星标当 i 的点；36–41s UI 组件（+ / 箭头 / 双箭头按钮）滑出，红色方块长出眼睛变成角色脸，随后一排 UI 组件横向拼满屏；45–58s 展示字体 Prostir Sans Heavy、Colors 色板、红黄青品牌色卡；59–71s 手机、水杯、腰包、蜡烛、名片等品牌触点快闪；72–78s 拼版海报落 "Excited!"。

## 动势
- 光标画形（9→12）：Movement 拖拽矩形 / Timing Fast Draw / Ease ease-out / Feeling Technical
- UI 组件墙展开（37.8→41.4）：Movement 横向右→左 / Timing Continuous Scroll / Ease linear / Feeling Catalog
- 品牌触点快闪（67→71）：Movement 每 0.3s 硬切 / Timing Beat / Ease snap / Feeling Montage

## 空间与布局
整段是"设计工具的视角"：所有元素都先以 wireframe/贝塞尔手柄/辅助线状态出现，再"定版"成干净图形；黑色背景始终是画桌，彩色物体浮在上面。转场核心是"先画后填"——任何元素都先以构造线出现，再变为成品。

## 可沉淀的 Pattern 候选
- **cursor-build-shape-to-brand**：光标拖出矩形 → 调圆角 → 变星标 → 贝塞尔线画结构 → 选色板，把 logo 从原始图形"做出来"（9→18）。解决"品牌 logo 如何被揭示而不是直接贴出"。
- **type-as-wireframe-then-resolve**：大字先以贝塞尔 construction guides / 红蓝手柄状态出现，辅助线收起变成干净字体（21→32）。解决"标题字如何带设计感地出现"。
- **ui-character-emerge**：一个红方块 UI 元件缩到中心长出眼睛变成角色脸，周围组件继续排列（36→41）。解决"UI 组件库如何长出性格"。
- **component-wall-horizontal-scroll**：一排 UI 按钮/卡片横向连续滑过拼成完整组件墙（37.8→41.4）。解决"组件库如何一次性展示丰富度"。
- **touchpoint-catalog-beat-cut**：品牌周边（T 恤/水杯/腰包/蜡烛/名片）每 0.3s 硬切快闪（67→71）。解决"品牌应用如何压缩成 montage"。
- **wipe-color-swatch-section**：斜杠 wipe 把色板一节擦出来（46.5→48.6）。解决"设计系统章节之间的硬分隔"。
- 注：3D 周边渲染为视觉处理层；不候选写实 3D 渲染本身。
