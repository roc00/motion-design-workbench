## 动势
- 杯→角色（1.3→3.9）：Movement 杯子缩小 + 角色从下进入 / Timing Slow Reveal / Ease ease-out / Feeling Cute
- 关键词蒙太奇（21→34）：Movement 角色横向走 / Timing 每 2s 一拍 / Ease linear walk / Feeling Dynamic
- 表情九宫格（37→39）：Movement 中心向外放射 / Timing Fast Pop / Ease elastic / Feeling Playful

## 空间与布局
整个片用双色板（深蓝/浅蓝）硬切做段落分隔，角色永远居中；关键词段是"大字在背景、角色在前景"的叠层，每拍角色换一个道具 pose。表情段用取景框把中心角色"框"成照片，再复制成网格。

## 可沉淀的 Pattern 候选
- **object-becomes-character-prop**：产品物件（咖啡杯）缩小，角色从下方冒出并接住杯子，完成"物→角色"归属转移（1.3→3.9）。解决"开场如何从产品自然引出吉祥物"。
- **character-walk-through-wipe**：角色在一个画面里向左走出画，下一个画面里角色从右走入，方向连续形成"走过画框"的无缝硬切（21→34 连续 7 次）。解决"多个 pose 关键词蒙太奇如何不生硬"。
- **pose-keyword-card**：背景大英文关键词 + 角色前景举对应道具 pose，每拍 2s（ACTIVE SOUL+球拍 / COFFEE MATE+杯 / COUPON MASTER+红包…）。解决"多个品牌人设关键词如何节奏化展示"。
- **face-closeup-to-emoticon-grid**：脸部特写白闪后，头部居中变成相机取景框，再复制成 8 个表情头像网格（35→39）。解决"角色表情库如何一次性展示"。
- **grid-to-circle-to-new-character**：表情网格中心留白放大成圆形光圈，圆里出现新角色变体（40→41.6）。解决"从主形象到衍生形象的 reveal"。
- **ball-to-character-gumball**：蓝色小球滚进扭蛋机，角色从机里出来（48.6→50.7）。解决"周边展示如何带点趣味收尾"。
- 注：3D 角色表演、咖啡豆粒子为视觉处理层；不候选写实 3D 渲染本身。
