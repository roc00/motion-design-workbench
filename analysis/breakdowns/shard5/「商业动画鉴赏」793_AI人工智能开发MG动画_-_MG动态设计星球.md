- 类型：MG 动画 / AI 企业宣传片（ALTEN 工程公司）

## 动势
- 头像链→球爆（0→6.5）：Movement 四周向中心再向外爆 / Timing Build-Up / Ease ease-out+elastic / Feeling Connected
- 方块拼 S→隧道（30→36）：Movement 中心拼装+Z 轴推 / Timing Slow Assemble / Ease ease-in-out / Feeling Technical
- UI 墙展开（96→104）：Movement 倾斜拉远 / Timing Slow Pull / Ease ease-out / Feeling Epic

## 空间与布局
全片以"节点→网络→界面→用户"为叙事轴：头像先连成链，链变成气泡宇宙；UI 元素先以簇状出现，簇再展开成满屏墙，墙再溶解回用户。浅蓝渐变背景始终是呼吸底，蓝/橙/青三色承担分组。

## 可沉淀的 Pattern 候选
- **avatars-link-to-chain**：用户头像圆从四周飞入，胶囊在节点间生长连接成对话链（0→4.8）。解决"多人/社交网络如何开场"。
- **center-orb-explodes-to-universe**：中心蓝球放大吞画，爆成气泡轨道宇宙（4.8→9.6）。解决"从节点链到平台世界观"。
- **blocks-assemble-then-tunnel**：小方块拼成字母/S 形，再变成立方体并长出嵌套透视隧道（30→36）。解决"抽象几何如何钻进下一段"。
- **cluster-to-full-wall**：中央 UI 簇倾斜拉远，展开成满屏透视 UI 墙（96→104）。解决"组件面板如何展示规模"。
- **wall-dissolves-to-users**：UI 墙溶解成蓝色空间，用户头像浮起（104→113）。解决"技术场景如何回到用户"。
- **blocks-compose-document-then-logo**：小方块拼成白色文档，文档变品牌旗标再变字（122→136）。解决"结尾收束到品牌"。
- 注：玻璃拟态质感为视觉处理层；机制可程序化。
