# panels/panel1_左上.mp4（Lovable 品牌片左上四分屏段）

## 基础信息
- 类型：品牌片 / 高能量字卡蒙太奇（Lovable AI 品牌片的 1/4 屏片段）
- 风格：米白纸张底 + 粉橙流体渐变波浪 + 粗黑无衬线大字；Playful/Premium
- 适用场景：AI 工具品牌开场、SaaS 官网 hero 循环、品牌片的"理念—数据—号召"段
- 时长 19.5s / 大致镜头数：cuts 14 个（集中在 6.4、9.9、15.9、17.5、19.1 的节拍点），约 12 个信息镜

## 镜头结构
0–5s 用气泡字卡讲"今天全球只有不到 1% 的人会写代码"的问题；5–8s 名字浮现（Meet → Lovable，心形 logo 与蓝紫底）；8–12s 甩到暗底"Start building ideas. Faster than ever before"；12–18s 用实时计数条"creating … new apps every day"把体量感砸出来；18–19s 收到星形 mark。整段是纯 typography + 流体渐变，无 UI 界面。

## 动势
- 乱码重组（5.5→6.5）：Movement 字母位内抖动 / Timing Fast Decode / Ease linear→snap / Feeling Technical
- 计数+波浪线（13.5→15.5）：Movement 数字向上滚动 + 线沿底部生长 / Timing Slow Continuous / Ease linear / Feeling Living/Dynamic
- 字→花形（17.5→18.5）：Movement 中心向外绽放 / Timing Fast Bloom / Ease ease-out+elastic / Feeling Playful

## 空间与布局
所有镜头都把视觉重心钉在中央文字槽位，背景流体渐变波浪只做上下涌动，不抢文字；转场要么在同一槽位换词，要么让一个词放大出血当作"门"。信息层级始终是「词→数字→品牌图形」三级。

## 可沉淀的 Pattern 候选
- **scramble-word-slot**：在同一中央文字槽位内，旧字母乱码抖动后逐位解码成新单词（5.5→6.5、12→13）。解决"理念句→动作号召句"的无缝切换。
- **word-by-word-sentence-build**：一句话拆成 3–4 拍逐词补全（but that's about→to change；new apps→every→day）。解决"一句话卖点如何卡节奏讲完"。
- **odometer-with-drawing-line**：数字滚动的同时，底部画一条渐变曲线，发光点沿线同步行走（13.5→15.5）。解决"抽象增长数字如何被看见"。
- **letter-zoom-through-logo**：把句尾单词（day）放大出血，白场中弹出品牌图形 mark（17.5→18.5）。解决"字卡段落如何收成图形 logo"。
- **liquid-gradient-section-divider**：粉橙流体波浪从底部涌满画作为段落分隔，再硬切到新色板（7→8、9.8→10）。解决"两段不同情绪之间的软过渡"。
- 注：流体波浪、星形绽放为视觉处理层，机制可程序化。
