# 你好，我是支小宝，你的AI生活管家 - 支付宝.mp4

## 基础信息
- 类型：AI 产品宣传片 / 角色 IP 片（支付宝支小宝）
- 风格：3D 柔和渲染 + 玻璃拟态卡片 + 浅蓝紫渐变气泡背景；Q 弹可爱
- 适用场景：C 端 AI 助手/语音助手产品的品牌片、App 上线片
- 时长 63.3s / 大致镜头数：cuts 5（1.44 / 6.12 / 40.56 / 52.76 / 63.28），绝大多数无缝，约 18–20 段

## 镜头结构
0–5s 从真实感书桌开场，小幽灵"支小宝"从手机里蹦出立 logo；6–18s 钻进手机演示"你说我办"：用户提问西湖玩法，AI 流式回答并给 CityWalk 路线；19–25s 输入框坍缩成星星，玻璃卡片从中心放射飞出展示"打车/星巴克/口令"等意图；26–31s 切"智能陪伴"页，相机推近角落小房子 icon 进入下一功能；32–40s 幽灵角色在屏幕里说话、周围卡片堆叠；41–50s 演示星巴克点单与外滩/黄山目的地；52–63s 镜头拉回书桌，手机翻面平放，文字落版。首尾用同一张书桌做书挡。

## 动势
- 输入框→星星→卡片放射（18.5→21.5）：Movement 中心向外 / Timing Collapse Fast then Radiate / Easing ease-out+elastic / Feeling Playful
- 标题页推近角 icon（28.6→31.2）：Movement Z 轴推进 / Timing Slow Push / Easing ease-in-out / Feeling Cinematic
- 拉远回书桌（52.76→55）：Movement Z 轴拉远 / Timing Slow Reveal / Easing ease-out / Feeling Bookend/Warm

## 空间与布局
开场与结尾用同一张 3D 书桌做"画框"，中间所有 UI 演示都发生在手机屏幕这个"画中画"里；玻璃卡片始终从中心星星或幽灵身旁飞出，保持一个情绪光源。转场核心是"手机屏幕=任意门"：推近进 UI，拉远回现实。

## 可沉淀的 Pattern 候选
- **intent-bar-to-burst-cards**：输入框坍收成一颗星星，多张意图卡片从星星放射飞出（18.5→21.5）。解决"一句话指令如何可视化成多种可能意图"。
- **corner-icon-drill-in**：卖点标题页四角各飘一个 3D icon，相机选其中一个角推近进入下一段（28.6→31.2）。解决"静态卖点页如何无缝进入下一个功能"。
- **bookend-desk-pull-out**：结尾镜头从 App UI 持续拉远回到开场的同一张书桌，手机翻面平放（52.76→55）。解决"功能演示如何收束回品牌情绪"。
- **character-plus-card-stack**：Q 弹角色居中偏右，证据卡从一侧飞入在其左侧堆叠，角色与文字同框（35.5→40）。解决"角色 IP 与功能证据如何同框不打架"。
- **same-layout-swap-content**：同一旅行卡片版式不动，只把图与文案从外滩换成黄山（45.5→49.4）。解决"多个同类功能点如何快切展示"。
- 注：3D 幽灵角色表演、书桌光影为视觉处理层，机制可程序化；不候选写实 3D 渲染本身。
