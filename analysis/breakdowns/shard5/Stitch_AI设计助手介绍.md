## 动势
- AI 响应链（18→25）：Movement 框变大→卡展开→三卡浮起 / Timing Slow Reveal / Ease ease-out / Feeling Technical
- 页面拆开露模特（32→37）：Movement 卡片翻折 / Timing Slow Peel / Ease ease-in-out / Feeling Cinematic
- 粒子聚合成脸（81→85）：Movement 粒子向中心汇聚 / Timing Slow Converge / Ease ease-in / Feeling Premium

## 空间与布局
紫青流体光晕是全片的"呼吸底"，UI 浮在黑底上；所有 UI 卡片都用圆角玻璃拟态，带霓虹描边。转场核心是"输入框=agent 化身"：输入框变大变回复卡，卡再分出结果卡；结尾粒子聚合成白脸完成"从产品到符号"。

## 可沉淀的 Pattern 候选
- **input-box-becomes-response-card**：输入框原地变大，loading pill 出现，再收窄成聊天气泡回复卡（18→21.6）。解决"AI 输入到响应的连续 UI 形态"。
- **loading-to-stream-to-cards**：Generating → 流式文字 → 三张结果卡模糊浮起（19.8→25.2）。解决"AI 等待感如何变成结果感"。
- **webpage-peels-to-reveal-assets**：落地页卡片像门一样翻开，露出它背后用的模特图/摄影（32.4→34.6）。解决"展示设计稿时如何暗示素材来源"。
- **page-to-side-devices**：网页与手机屏并排漂浮，表达同一设计的多端适配（34.6→37.8）。解决"响应式设计如何一眼看懂"。
- **liquid-gradient-section-divider**：紫青流体涌满画作为段落分隔，再散开露出下一节（38.77→41.4、50.4→52.2、57.93→61.2）。解决"深色 AI 产品片的段落呼吸"。
- **particles-converge-to-logo-face**：粒子场汇聚成白色两点脸，脸模糊成字（81→86.4）。解决"结尾如何从氛围收到品牌符号"。
- 注：紫青流体光晕、玻璃拟态为视觉处理层；不候选写实 3D 渲染。
