## 动势
- 胶囊分裂成工具栏（50.4→52.8）：Movement 单一物体内部分裂 / Timing Slow Open / Ease ease-out / Feeling Tactile
- 液体倒入托盘（66.3→71）：Movement 一端→另一端 / Timing Slow Pour / Ease linear / Feeling Material
- UI-on-scene 换背景（120→129）：Movement 背景切，UI 不动 / Timing Hard Cut / Ease snap / Feeling Product

## 空间与布局
所有玻璃组件都浮在极简白色台面或自然摄影背景上，组件永远居中；转场不靠运动而靠"材质连续性"——玻璃折射、高光、阴影始终一致。同一组件可以在不同摄影背景间切换而不破坏识别。

## 可沉淀的 Pattern 候选
- **pill-splits-into-toolbar**：单个玻璃圆角胶囊在内部"长出"分隔，分裂成 ○△Done 三段工具栏（50.4→52.8）。解决"单按钮如何展开成工具组"。
- **glass-ui-on-scene**：同一个玻璃 UI 组件漂浮在不同摄影背景（花/沙丘/水滴）上，背景硬切但 UI 不动（120→129）。解决"设计系统组件如何在真实场景里被感知"。
- **liquid-into-glass-tray**：绿色/蓝色液体从一端流进透明玻璃托盘，填充其中（66.3→76.8）。解决"slider/toggle 的填充态如何被材质化"。
- **wireframe-to-solid-icon**：图标先以线框/线稿状态出现，再长出实体 3D 质感（136.8→146.4）。解决"图标如何从线稿到成品"。
- **finger-press-reveals-menu**：手指按玻璃圆钮，按钮发光，下方弹出下拉菜单（52.8→57.6）。解决"玻璃按钮的可点击反馈+popover"。
- 注：水滴/水流/玻璃折射为材质渲染层，机制可程序化；不候选写实 3D 渲染本身。
