# TRAE - solo.mp4

## 基础信息
- 类型：AI 编程 IDE 产品发布片（TRAE 2.0 SOLO）
- 风格：深炭灰 + 荧光绿品牌色，几何方块/点阵语言，极简技术感；白/黑底交替
- 适用场景：开发者工具、AI Agent、IDE 类产品的发布/功能演示视频
- 时长 / 大致镜头数：139.2s；cuts.txt 仅 14 个硬切点，以无缝/隐形衔接为主，实际场景约 25 个

## 镜头结构
开场（0–9s）从一句口号"Collaborate with Intelligence"起，一个黑方块旋转炸开成点阵再聚合出 TRAE 字标，完成品牌登场。接着（9–33s）用"上下文工程师"概念字卡 + 麦克风图标 + 提示框建立"一句话生成"的产品叙事。中段（36–117s）是主体：IDE 界面长镜头式走查——从 SOLOcoder 聊天、实时编辑、写产品需求文档，到从零搭出一个电影网站 demo、代码智能续写、自动生成注释、创建测试用例，几乎全是录屏/UI 连贯推进。段间反复用绿色九宫格 TRAE 品牌卡做"章节呼吸点"。结尾（120–137s）由九宫格收拢成字标块，再到 SOLO 缩写拆解（Self Optimized Learning Operator），最后字标从横条叠起组装、落深色版。整体节奏：UI 走查段长镜慢推，品牌卡段短促有力。

## 动势（挑典型）
- **方块炸开→聚合 logo（2–7s）**：Movement=中心向外散 → 由外向中心收；Timing=先爆后聚；Easing=聚合段弹性 spring；Feeling=Technical/Premium。
- **九宫格向心收拢（120.8–122s）**：Movement=四周→中心；Timing=Fast Out；Easing=ease-in；Feeling=Premium/Cinematic。
- **横条叠起组装 logo（132.5–135s）**：Movement=自下而上堆叠 + Z 轴微缩；Timing=Slow Build；Easing=ease-out；Feeling=Technical。

## 空间与布局
- 全片在"白底网格"与"深炭底"两种空间间交替：白底放字卡与说明，深底放 UI 与品牌卡，靠同一荧光绿串场。
- 品牌九宫格既是章节分隔也是空间枢纽——中央黑块始终不动，周围格按功能填充，收拢时只留中心，形成"总览→聚焦品牌"的层级。

## 可沉淀的 Pattern 候选
- **primitive-explode-reassemble-logo**：一个基础方块先旋转炸开成粒子点阵，再由粒子反向聚合组装成字标。证据 2–7.2s。解决：用一个动作同时完成"原子感"与"品牌登场"，首尾还能复用。
- **grid-collapse-to-brand**：3×3 功能网格四周格逐个退场，只留中央品牌块。证据 120.8–122s（79/103/110 为其反向展开）。解决：把"功能全景"快速收束到"品牌核心"。
- **brand-block-to-ui-card-morph**：品牌纯色方块直接形变缩小为深色产品 UI 卡。证据 122.2s。解决：品牌符号无缝进入产品界面。
- **center-logo-orbit-agents**：中心 logo 向外辐射连线到环绕节点，右侧卡循环切换对应节点。证据 123.5–125s。解决：可视化"一个枢纽调度多个工具/Agent"的拓扑关系。
- **accent-bar-acronym-highlight**：缩写英文逐词下方绿色高亮条扫过，再字距拉开 + 中文打字机副标题。证据 126.5–130.5s。解决：把缩写词的每个字母/词讲清楚的字卡收尾。
- **bar-stack-logo-assemble**：横向色条自下而上堆叠组装成字标块，再长细节。证据 132.5–135s。解决：与开场呼应的高精度落版。
- 灵感参考：电影网站 demo 本身为录屏成果，不单独做转场候选。
