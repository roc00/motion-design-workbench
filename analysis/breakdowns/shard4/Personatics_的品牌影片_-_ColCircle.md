# Personatics 的品牌影片 - ColCircle.mp4

## 基础信息
- 类型：金融/银行设计系统品牌影片（Cognitive Banking）
- 风格：超写实 3D 渲染 + 高饱和色板 UI，核心母题"圆"（coin / dot ring / avatar circles / ring chart / vault）
- 适用场景：金融科技、设计系统、品牌世界观类高端品牌片
- 时长 / 大致镜头数：90s；cuts.txt 29 个切点，约 35 个镜头

## 镜头结构
开场（0–16s）从一枚银币在城市/草地/摩天楼间悬浮旋转起，借圆形匹配把银币接成手机屏上的点阵圆环，点阵收敛成黑色圆标，再绽开成人物头像圆环，完成"钱→人→品牌圆"的叙事。中段（18–70s）高密度展示 UI 与生活场景：电商商品流、购物车、工作台、银行 dashboard、学生贷款、多时区时钟、彩色拱门 3D，再到"Cognitive Banking"发光字、彩色丝带、按钮组件、情侣与有车一族生活场景，段落间用圆/弧线串接。尾段（72–88s）由"Goal Milestone"环形图匹配到银行金库圆门，门打开后镜头穿进金库长廊，最后落到湖边房子远景收束。整体电影化运镜，单镜 2–4s。

## 动势（挑典型）
- **银币→点阵→黑圆→人脸圆（0–17s）**：Movement=先平移追踪银币，再 Z 向收拢，再绽开；Timing=Slow Build；Easing=ease-in-out；Feeling=Cinematic/Premium。
- **丝带汇聚成按钮（51.5–55.8s）**：Movement=多线扫过→中心汇聚成点→横向拉长；Timing=Fast Converge；Easing=ease-in；Feeling=Dynamic/Premium。
- **金库圆门推进（74.9–80s）**：Movement=Z 轴推进 + 门旋开；Timing=Slow Reveal；Easing=线性；Feeling=Cinematic。

## 空间与布局
- 全片以"圆"为统一形状锚：实拍银币、UI 点阵、头像环、环形图、金库门都是同一个圆，跨空间切换时靠圆形对齐完成匹配剪辑。
- 抽象彩色丝带/弧线作为"共享元素"在段落间飞行，把黑底组件段和生活场景段缝在一起。

## 可沉淀的 Pattern 候选
- **circle-motif-match-cut-chain**：把同一"圆"在不同镜头间替换语义（银币→点阵环→实心 logo→人脸圆环→环形图→金库门），靠形状对齐硬切。证据 11.5–17s、74.9s。解决：用一个几何母题串起实拍/UI/3D 多种空间。
- **ribbon-converges-to-button**：多条彩色丝带扫过黑底后汇聚成一个圆点，圆点拉长为圆角 CTA 按钮，文字与周围组件随后组装。证据 51.5–55.8s。解决：把"抽象动势"落点成"具体 UI 按钮"，完成从概念到组件。
- **ring-to-vault-door-zoomthrough**：UI 环形图形状匹配到 3D 圆形门，门旋开后镜头穿过门洞进入纵深长廊。证据 74.9–80s。解决：把数据可视化圆环升级为可穿行的空间入口。
- **coin-dots-solid-logo-burst**：立体圆币→屏幕点阵环→点阵收成实心圆→绽开成用户头像环簇。证据 11.5–17s。解决：开场同时讲清"钱—用户—品牌"三层含义。
- **arc-sweep-between-cards**：一条绿黄渐变弧线沿卡片底部扫过，连接堆叠的 UI 卡。证据 72–74.5s。解决：卡片组之间的连续引导线。
- 灵感参考：超写实 3D 生活场景（湖边房子、情侣、车）为美术渲染，不单独做转场候选。
