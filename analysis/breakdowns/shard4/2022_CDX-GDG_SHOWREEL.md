## 基础信息
- 类型：设计 Showreel（DiDi CDX 设计团队年度作品集，偏 App UI 与品牌系统）
- 风格：浅色留白 UI 蒙太奇 + 橙色品牌色 + 少量 3D 卡通场景；干净、克制、信息密集
- 适用场景：互联网/App 设计团队年度 showreel、品牌设计系统发布、产品多界面集锦类视频
- 时长 / 大致镜头数：179.7s；cuts.txt 检测到 32 个硬切点，实际镜头/场景约 60+ 个（大量 UI 屏为同背景硬切）

## 镜头结构
开场（0–12s）先用深色终端数字"2.16M"建立年度体量感，转入工作台汽车草图 3D 场景，再通过圆形舷窗把 CDX 字标"推"进太空场景完成 logo 登场。中段（12–137s）是主体：连续的 App 界面屏——手机/平板样机在统一浅色渐变背景上依次排开，展示网约车、外卖、支付、钱包等多个产品线界面，靠样机与背景连续性硬切。尾段（139–179s）由橙色对角擦入转入字体与设计系统展示（DIDI SANS PRO、线条制图、Variable 字阶），最后以品牌标识蒙太奇 + 纸屑"HI!2023"收束落版。整体节奏为快切 UI 蒙太奇为主，单镜约 1.5–3s，开场/结尾 3D 段落稍长。

## 动势（挑典型）
- **圆形舷窗推穿（6.4–11s）**：Movement=Z 轴正向推进；Timing=Slow Reveal（匀速缓推）；Easing=ease-in-out；Feeling=Technical/Cinematic。圆环比内景更快出画形成视差。
- **橙色对角楔形擦入（139.2 / 141.6s）**：Movement=右上→左下对角；Timing=Fast Start 快入；Easing=ease-out；Feeling=Premium。楔形一旦覆盖即切换，干净利落。
- **单卡→多卡增殖（132–138 / 166.2s）**：Movement=中心向外扩散 + 整体斜向旋转；Timing=Slow Build；Easing=弹性 spring；Feeling=Playful/Dynamic。

## 空间与布局
- 主体段所有 UI 屏共用同一浅色渐变背景与居中样机框，空间"原地不动"，只换框内内容，靠 device-frame-continuity 把几十个界面缝成一条连续翻阅流。
- 3D 段落（舷窗、舞台、桌面）用 Z 轴推近与对角擦除制造纵深，把"产品 UI 集锦"和"品牌世界观"两种空间用一次圆形推穿和一次橙色擦除分隔开。

## 可沉淀的 Pattern 候选
- **circular-porthole-zoomthrough**：一个圆形仪表/舷窗遮罩把 logo/主体框住，镜头沿 Z 轴推近，圆环刻度比内容快出画，实现"钻进圆孔进入新世界"。证据 6.4–11s。解决：从实拍/工作台场景无缝进入 logo 世界观。
- **brand-color-diagonal-wipe**：用品牌橙色做成对角楔形/三角形，先扩张覆盖全屏再退白进入字卡。证据 139.2s、141.6s。解决：在 UI 蒙太奇与品牌字卡之间做一次有方向、有色标的章节切换。
- **device-frame-continuity-reel**：统一背景 + 统一样机框，框内内容硬切替换，把几十个产品界面缝成"同一场景里翻阅"的连续流。证据 21.6–136s 整段。解决：多界面 showreel 不零碎。
- **element-clone-multiply-with-parallax**：单个功能卡克隆增殖成斜向漂浮阵列，再用运动模糊切到下一屏。证据 132–138s、166.2s、169.3s。解决：用"一→多"直观表达多语言/多版本/多货币。
- **typewriter-endcard-after-color-wipe**：色块铺满退白后，字符逐字打出品牌字标。证据 141.6–142.5s。解决：设计系统/字库发布的落版。
- 灵感参考：蛋糕/舞台/太空等写实 3D 卡通场景与纸屑爆开为美术风格，不单独程序化候选。
