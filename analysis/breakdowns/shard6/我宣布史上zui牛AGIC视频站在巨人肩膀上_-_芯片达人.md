# 我宣布史上 zui 牛 AGIC 视频：站在巨人肩膀上（ASML）

## 基础信息
- 类型：品牌史诗片（AI 生成电影感 ASML 宣传片）
- 风格：写实电影感 3D 渲染，暖冷色章节，史诗级运镜
- 适用场景：科技品牌史诗感开场、行业叙事片
- 时长 / 大致镜头数：111s / cuts 18 个，约 40+ 镜头

## 镜头结构
- 0–5s：黑场小字字幕 → ASML logo。
- 7–16s：白色实验室→紫色光刻光效（ASML 核心意象）。
- 18–27s：晶圆特写→城市航拍→天台人物，用漏光/光感转场。
- 28–35s：蓝色隧道→芯片特写→办公室。
- 36–43s：程序员→电路板→街机→AIIS 标志。
- 45–52s：芯片辉光→办公室→芯片。
- 54–61s：城市天际线→演讲者→特斯拉式人物。
- 63–70s：教堂→乡村→窗边女性。
- 72–82s：星云→牛顿与苹果→行星。
- 84–90s：黑洞→像素城市→踢球少年。
- 90–102s：高速运动模糊蒙太奇（速度斜坡）。
- 104–111s：ASML logo 落版。
- 节奏：前段慢（4–5s/镜），90s 后爆发快切。

## 动势
- 高速蒙太奇（90–102s）：Z 轴高速推进，速度斜坡（慢→快→慢），运动模糊。Easing ease-in-out。Feeling Cinematic / Epic。
- 星云到行星（72–76s）：camera-orbit 环绕行星，慢推。Feeling Cinematic。

## 空间与布局
- 全片靠颜色章节组织：紫（光刻）→暖金（城市）→蓝（芯片）→绿（办公）→紫（人物）→宇宙。每段内部用漏光/辉光做无缝桥。

## 可沉淀的 Pattern 候选
1. **light-leak-chapter-cut**：两镜之间用彩色漏光/色散光带扫过画面隐藏切点（18s / 37s / 45s）。解决：史诗片跨景别转场。（部分灵感参考，漏光本身可程序化）
2. **speed-ramp-blur-montage**：高速运动模糊连续藏切多个场景，速度先慢后快再慢（90–102s）。解决：把多个意象压缩成一段"情绪爆发"。
3. **particle-logo-aggregate**：粒子聚合成品牌字母/logo 落版（104–106s）。解决：品牌收尾。
4. 写实电影感运镜与人物表演（天台、牛顿、演讲者）为灵感参考，不候选。
