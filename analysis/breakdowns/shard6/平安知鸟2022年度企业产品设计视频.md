# 平安知鸟 2022 年度企业产品设计视频

## 基础信息
- 类型：B2B 企业培训平台年度设计 showreel
- 风格：3D 微拟物 + 扁平 UI 交替，主色橙红/白/灰，章节化"XX 篇"结构，有粉色小鸟 IP
- 适用场景：企业级产品/平台年度设计盘点、B 端品牌片
- 时长 / 大致镜头数：150.3s / cuts 38 个，约 55+ 镜头

## 镜头结构
- 0–7s：3D 立体"知"字旋转并从白到橙红渐变填充，变形成知鸟 logo 浏览器窗口，橙色竖帘拉开进入"产品体验篇"。
- 9–22s：LIVE 演播台→手机直播演示→AskBob 专家→虚拟人头像。
- 24–34s：知鸟数智桌面→知鸟学→3D 金属器物。
- 36–46s：知鸟学习地图→UI 拆解成等距 3D 城市→知识农场橙色章节。
- 48–58s：知识农场手机→知鸟勋章→知鸟电子书→知鸟数舱深色 dashboard。
- 60–68s：深色数据可视化→"品牌视觉篇"。
- 70–80s：知鸟数字产品矩阵→等距图标矩阵→粉色小鸟 IP 登场。
- 82–94s：功能海报→节日海报→巅峰讲堂栏目包装。
- 96–106s：平安知鸟舞台→橙色 3D 弹珠迷宫→知鸟 8 周年。
- 108–118s："生态系统篇"→设计系统色板/组件。
- 120–126s：Z-Design dashboard→"国际奖项篇"。
- 128–142s：嵌套矩形隧道推入→依次浮现 IF / IDEA / 亚洲设计奖 logo。
- 144–150s：知鸟 logo 落版。
- 节奏：章节标题卡 3s/张，产品演示 3–5s/张。

## 动势
- 3D 知字填充（0–4s）：缓慢旋转 + 颜色从白到橙红 ease-in-out。Feeling Premium。
- UI→等距城市（36–42s）：平面 UI 先散（Fast Out）再长成城市（Slow Build），手机浮起 ease-out。Feeling Technical / Premium。
- 奖项隧道推入（128–134s）：Z 轴匀速推入嵌套矩形，隧道收敛到中心，ease-in。Feeling Cinematic。

## 空间与布局
- 全片以"章节标题卡"为结构骨架（产品体验篇/品牌视觉篇/生态系统篇/国际奖项篇），每章一个大色/氛围；3D 等距城市与浏览器窗口反复出现，做"数字世界"的母题。

## 可沉淀的 Pattern 候选
1. **3d-glyph-color-fill**：一个 3D 立体汉字先旋转再做颜色渐变填充，作为品牌开场（0–4s）。解决：汉字 logo 的 3D 登场仪式。
2. **glyph-to-app-window**：3D 汉字直接变形成一个浏览器窗口/设备框，logo 在框内（4.5–6s）。解决：品牌字→产品界面的无缝桥。
3. **ui-flip-to-isometric-city**：平面 UI 截图破碎成等距小方块，再生长成等距 3D 城市（36–42s）。解决：把"界面"抽象成"数字生态"的空间隐喻。
4. **nested-rect-tunnel-award-reveal**：镜头推入层层嵌套的矩形隧道，隧道收敛后浮现金属质感奖项 logo（128–134s）。解决：奖项/荣誉段的仪式感。
5. **chapter-title-card-repeat**：每章用同一版式的标题卡（大字章节名 + 小字副标），做段落切分（7s / 67s / 108s / 124s）。解决：长 showreel 的章节导航。
6. **vertical-blinds-wipe**：橙色竖帘从侧拉开揭示下一镜（6–7.5s）。解决：章节切换。
