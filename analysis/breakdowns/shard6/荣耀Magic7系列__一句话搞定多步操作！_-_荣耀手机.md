# 荣耀 Magic7 系列 一句话搞定多步操作！

## 基础信息
- 类型：手机产品功能宣传片（YOYO 智能体）
- 风格：浅色极简 UI 演示，白底到浅灰渐变，手机模型居中，左右两侧用蓝/灰字旁白
- 适用场景：AI 手机/系统级智能体功能演示、一句话操作类卖点视频
- 时长 / 大致镜头数：69s / cuts 仅 2 个硬切点（0.03 / 21.37），即全片几乎一条连续镜头，约 8 个功能演示段

## 镜头结构
- 0–5s：暗场中 "YOYO" 字样浮现，一个发光小光球（YOYO 形象）从字母 O 的位置升起，语音输入 pill 同时出现。
- 5–18s：第一个用例"购物比价"：手机亮起展示电商列表，左右两侧蓝/灰字旁白（价格眼花缭乱 / 一句话购物比价 / 不花冤枉钱）。
- 19–27s：第二个用例"帮点咖啡"：手机切换到咖啡 App 列表，旁白（帮点咖啡 / 一句话的事儿）。
- 28–43s：第三/四个用例"总结文件自动发送"、"续费 APP 自动取消"：手机屏幕内容连续切换。
- 44–51s：YOYO 光球漂浮，多窗口 UI 在手机周围扇形堆叠展示能力。
- 52–57s：左右两部手机并排，左边任务列表、右边结果页（一键填表/探店地址）。
- 58–64s："有事？找 YOYO 智能体" + "更多使用场景持续解锁中" pill。
- 65–69s：暗场 MagicOS logo → HONOR 落版。
- 节奏：每个用例 6–10s 可读，用例间靠光球与 pill 连续。

## 动势
- 光球升起（0–4s）：从字母 O 位置慢起，ease-out，带辉光。Feeling Premium。
- 多窗口堆叠（45–50s）：手机窗口围绕光球扇形展开，stagger 弹性。Feeling Playful / Premium。
- 字幕淡入（13–18s）：左右文字极慢淡入，不抢屏幕内容。Feeling Technical。

## 空间与布局
- 全片统一浅白底，手机居中偏下，左右两侧留白放旁白文字；YOYO 光球与底部 pill 是两个常驻视觉锚，用例切换时二者不动，只换手机屏幕内容——这是全片无缝感的核心。

## 可沉淀的 Pattern 候选
1. **persistent-pill-and-orb**：一个语音 pill 与一个角色光球作为全片常驻锚点，用例切换时二者位置不变，只换中间手机屏幕内容（5–43s）。解决：多用途演示片在多个用例间不切黑、不跳轴。
2. **side-annotation-dual-text**：手机屏幕左侧放蓝色"任务"文字、右侧放灰色"结果/收益"文字，屏幕内容不动，文字淡入淡出讲因果（13–18s / 22–27s）。解决：让录屏演示自带旁白，无需配音。
3. **orb-orbit-card-fan**：角色光球作为聚合点，多张手机窗口围绕它扇形展开表达"多任务/多能力"（45–50s）。解决：抽象"智能体同时处理多事"的可视化。
4. **task-result-split-phone**：左右两部手机并排，左边任务列表、右边执行结果，同一操作因果并排可读（52–57s）。解决：AI 智能体"一句话→多步执行"的因果对比。
