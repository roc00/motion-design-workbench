# 品牌案例分享 Google 的新 AI Bard（品牌黑洞工作室）

## 基础信息
- 类型：产品发布式品牌短片（Google Bard/Gemini 更名叙事）
- 风格：青蓝渐变底 + 大留白，扁平 MG，Google 品牌色，极简字卡与 UI 卡片交替
- 适用场景：品牌更名/产品名升级、功能集成宣传、AI 助手发布
- 时长 / 大致镜头数：35s / cuts 15 个，约 18 镜

## 镜头结构
- 0–5s：渐变底上短句字卡（New way of / Things / open the / and type it in），用 kinetic type 铺垫"新方式"。
- 5–12s：Bard logo → "Google" 字母从散落状态聚合成词 → Google 全家桶图标墙。
- 13–18s：手机韩语搜索 → "Now on mobile" → Gemini 新 logo → "It's everything" 漂浮字群。
- 18–26s：Workspace 文档 → 提示词 pill 输入示例（整理邮件 / 推荐餐厅）→ 结果 checklist。
- 26–35s：手机端 Gemini 演示 → 大 toggle 开关 "on the / Phone" → "Now on mobile" → 黑场 Google g 落版。
- 节奏：字卡 1.3s/镜，UI 演示 3–4s/镜。

## 动势
- 字母聚合（7.8–9.1s）：散落字母先散开再 scramble 聚合，Fast In（散）→ Slow Out（聚）。Easing ease-in-out。Feeling Technical。
- toggle 滑动（28.6–29.9s）：圆形滑块从左到右匀速滑过，弹性弹簧收尾。Feeling Playful / Premium。
- 漂浮字群（16.9s）：多组 "It's everything" 以不同透明度缓慢漂移。Feeling Cinematic。

## 空间与布局
- 全片统一青蓝渐变底，所有字卡/UI 卡片居中或左对齐；唯一空间变化是手机与文档卡片的"嵌入"，用 pill 输入框在它们之间搭桥。

## 可沉淀的 Pattern 候选
1. **letter-scramble-assemble**：品牌名字母先散成粒子再 scramble 聚合成完整词（7.8–9.1s）。解决：品牌更名/新词登场时的仪式感，比淡入高级。
2. **toggle-slide-as-transport**：用一个大号 toggle 开关的左右滑动同时承担"转场"和"功能开启"双重语义，开关上文字随滑动变化（28.6–29.9s）。解决：把产品功能（移动端开启）和镜头转场合二为一。
3. **pill-input-result-loop**：同一个胶囊输入框先显示输入，再在其下方生成结果卡片（20.8–23.4s）。解决：AI 产品"输入→响应"的最小可视化单元。
4. **word-cloud-background**：同一句 slogan 以不同透明度重复铺满屏幕作为章节底纹（16.9s）。解决：抽象 slogan 的情绪化强调。
