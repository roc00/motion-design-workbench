# Vivo 游戏 2022 设计年鉴

## 基础信息
- 类型：游戏中心 UED 年度设计 showreel
- 风格：高饱和角色 IP + 扁平 UI 演示交替，章节大色块（深空黑/霓虹红/青/橙红/春节红/紫蓝），角色"知壹"贯穿
- 适用场景：平台/社区类产品年度设计盘点、带 IP 形象的功能集合片
- 时长 / 大致镜头数：90.2s / cuts 37 个，大量 1–2 秒快切蒙太奇，约 50+ 镜头

## 镜头结构
- 0–7s：一颗小皇冠图标→粉色光球生长→黄色光环闭合→角色"知壹"立绘+绿色斜 banner"知壹，很高兴认识你"。
- 9–20s：知壹三个角色段（小编辑/小玩伴/小助手），每段配绿色斜 banner 标签，中间穿插游戏中心 UI 截图。
- 21–27s：红黄闪电式快闪蒙太奇（cuts 密集），知壹小玩伴登场。
- 28–35s：青色闪光转场 → 控制室 → 小黄鸭头盔角色 → 游戏 UI。
- 36–43s：橙色章节"知壹小助手 带你体验更多精彩"，福利 UI。
- 45–52s：春节红色章节，春节活动 UI。
- 54–62s：深色模式/字体设置演示 → "游戏节"活动 logo → 3D 空间小场景。
- 63–72s：3D 虚拟演播厅/演唱会空间运镜（灵感参考）。
- 73–89s：知壹挥手告别 → UI 网格 → 紫蓝竖排文字 → VMIC UED logo → 彩色皇冠形成 → vivo 游戏中心落版。
- 节奏：角色段 2–3s/镜，UI 段 2s/镜，章节切换靠颜色块与 banner。

## 动势
- 图标→角色（0–7s）：中心对称缩放，光球先长再环再角色，ease-out + stagger。Feeling Playful / Premium。
- 闪电快闪（21s）：红黄闪电图形高速横扫，Fast In Fast Out。Feeling Dynamic。
- 皇冠聚合成 logo（84–86s）：粒子向中心聚合，ease-in。Feeling Cinematic。

## 空间与布局
- 全片以"知壹"立绘为视觉锚，每个角色段（小编辑/小玩伴/小助手）用同款绿色斜 banner 标签标注身份；章节之间靠整屏大色块翻色，UI 演示始终放在手机竖框里。

## 可沉淀的 Pattern 候选
1. **role-banner-sticker**：同一角色立绘上叠加同款斜角彩色 banner 贴纸，banner 文字随章节换（小编辑/小玩伴/小助手）（9s / 25s / 36s）。解决：IP 角色多身份段落的快速标签化。
2. **orb-ring-character-birth**：小图标→光球→光环→角色立绘的连续几何形变开场（0–7s）。解决：IP 角色登场的仪式感。
3. **lightning-flash-wipe**：红黄高饱和闪电图形作为方向擦除，藏住快速蒙太奇切点（21–23s）。解决：高能快切段的转场。
4. **logo-particle-assemble**：彩色皇冠 logo 从粒子聚合成形做落版（84–86s）。解决：品牌 logo 收尾。
5. 3D 虚拟演播厅运镜（63–72s）为灵感参考，不可程序化。
