# @creatoroly motion design showreel 25.

## 基础信息
- 类型：个人/工作室 motion design showreel（作品混剪 + 自述旁白）
- 风格：白底为主的扁平 MG + 玻璃拟态卡片，章节用大色块（白/薄荷绿/深黑）切换，收尾星巴克/YouTube 梗段
- 适用场景：设计作品集、个人频道包装、轻量产品系列演示
- 时长 / 大致镜头数：44.9s / cuts 仅 5 个硬切点（10.7 / 18.6 / 26.0 / 30.75 / 35.0），大量无缝切，约 25+ 镜头

## 镜头结构
- 0–5s：白底短句字卡 "it's like" 串联地图/聊天气泡 UI，语速极快建立叙事 hook。
- 5–13s：薄荷绿色块章节（Goomba 梗），结尾用一枚发光蓝色圆环进入下一章。
- 13–24s：深色章节（Portal 产品演示）：光环 → "What is Portal?" → 三人头像 → "Choose a Portal" → 回到浅色 UI 文件管理。
- 24–31s：SHEEVY/Sheevon Salmon 人物梗段，polaroid 照片堆叠 → YouTube 订阅卡。
- 31–43s：WWDC25 曲线丝带 → 绿色圆角 blob 段落 → 星巴克下单全流程（logo→杯→下单卡→配送 tooltip）→ "TO BE CONTINUED"。
- 节奏：字卡段 1.3s/镜，产品演示段 3–5s/镜，章节之间靠色块与发光元素转。

## 动势
- 蓝环→Portal 场景（13s）：Z 轴穿过圆环，先慢后快再减速到位。Easing ease-in-out。Feeling Cinematic。
- polaroid 堆叠（26–28s）：多张照片错落旋转堆叠，弹性 spring。Feeling Playful。
- 绿色 blob 升起（32s）：底部 blob 缓出，图标依次错落下落。Easing ease-out + stagger。Feeling Playful。

## 空间与布局
- showreel 靠"色块章节"组织空间：白/薄荷绿/深黑三块背景各占一段，章节内元素全部居中或对齐网格；跨章节时用一个发光物体（蓝环）或形状（胶囊→视频卡）做视觉桥。

## 可沉淀的 Pattern 候选
1. **block-color-chapter-flip**：整屏背景色做章节标记，跨章时前景保留一个同色/同形状元素做桥（白→绿→黑）（6.5s / 18s / 32s）。解决：showreel 式混剪需要快速换段又不晕。
2. **logo-lands-on-product**：品牌 logo 先以独立图形出现，下一镜"落到"产品表面成为产品上的图案（星巴克 logo→纸杯印章）（35–37s）。解决：品牌识别与产品展示合并成一次连续动作。
3. **polaroid-stack-relay**：同一人物素材先做海报，再缩小为 polaroid 卡片堆叠，再翻面为订阅卡（24–29s）。解决：把同一素材在"海报→照片→订阅卡"三种形态间连续复用。
4. **ring-as-portal**：发光圆环作为画框，镜头穿过环进入下一镜（10–14s）。解决：抽象"点击进入/打开产品"。
5. **blob-container-pop**：新章节以液体感圆角 blob 从底升起作为新内容容器，图标/文字落到 blob 上（32–34s）。解决：软萌/Playful 调性下的章节开场。
