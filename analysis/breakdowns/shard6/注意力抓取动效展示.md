# 注意力抓取动效展示

## 基础信息
- 类型：技术解释型产品宣传（Appstack 归因工具）
- 风格：深色科技感 + 辉光粒子，冷蓝主色，章节间用蓝→绿→红做情绪转场
- 适用场景：开发者工具/AI 基础设施/API 类产品的概念解释片
- 时长 / 大致镜头数：24.7s / 约 12–14 镜（cuts.txt 仅 4 个硬切点：1.77 / 2.40 / 4.57 / 4.63，其余均为无缝衔接）

## 镜头结构
- 开场 0–4s：大字 kinetic type（Unlock → Appstack's → Funiverrr），用字母变形建立叙事主语。
- 中段 5–14s：一条 URL 输入 pill 作为主角，从蓝色光粒中浮现，文字逐字打出、光标形态变化、再被绿色雷达圈包裹；随后切到一台倾斜的 iPhone 录屏演示归因链路。
- 后段 15–24s：蓝色光带扫过→终端窗口浮现代码→大背景字 "DESIGN / ENDPOINT" 托字卡→红辉光章节收尾（This is important / red terminal）。
- 混合节奏：字卡段快（1s/镜），UI 演示段慢（3–4s 可读），章节切换靠颜色与光。

## 动势
- URL pill（5–9s）：中心静止，内部文字水平打字机推进；外围绿环从中心向外 expand。Timing：文字打出快（fast typing），圆环扩散慢（Slow Reveal）。Easing：打字线性，圆环 ease-out。Feeling：Technical / Cinematic。
- 蓝光横扫（15s）：水平 Z 轴光带从左到右，Fast Start + Fast Out，运动模糊藏切。Easing：线性高速。Feeling：Dynamic。
- 径向隧道（20s）：中心向外 blur 扩张，ease-in-out。Feeling：Cinematic。

## 空间与布局
- 全片以"中央锚点"组织：pill、iPhone、终端、隧道光圈都在画面几何中心，章节切换时中心物体不变或被光/字重新定义；UI 元素始终不居中铺满，留出暗场做辉光。

## 可沉淀的 Pattern 候选
1. **kinetic-type-to-ui-background**：前景大字退到背景层变为半透明底纹，前景再升起 UI 框（1.0s / 16s / 21s）。解决：用文字同时承担"标题"和"章节底纹"两种角色，避免字卡→UI 的硬切。
2. **color-chapter-glow**：章节切换时用同一中心物体上的辉光颜色做连续变化（蓝→绿→红），颜色即章节标签（9s / 23s）。解决：在无对白节奏下给观众"换章"信号。
3. **pill-state-carrier**：同一个胶囊输入框作为主角跨多帧存在，内部只换状态（占位符→打字→loading→对勾）（5–8s）。解决：让抽象的"输入→响应"流程可视化，容器不动降低认知负荷。
4. **radial-portal-blur**：中心元素拉出径向模糊隧道再爆开成新场景（20s）。解决：抽象"进入下一环节"的转场，比淡入淡出更有科技感。
5. **cursor-drills-into-device**：设备框保持不动，白色光标在屏幕内画选区/指点，视线被光标带入屏幕（11–14s）。解决：录屏演示与实拍设备之间的视线连续。
