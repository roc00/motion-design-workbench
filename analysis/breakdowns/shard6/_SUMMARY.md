## 二、Pattern 候选（按频次排序，≥2 个不同视频标「高频」）

### 高频（≥2 个不同视频）

1. **glow-light-transition / 辉光藏切** 【高频】—— 一道光/辉光/漏光/闪白在切点处亮度峰值藏切。
   - 注意力抓取（4s/9s/15s/20s/23s）、creatoroly（10s）、Vivo（12s/28s）、AGIC（10s/18s/37s/45s）、Framer（0s/9s/50s）、蚂蚁（3s/6s/63s/88s）
2. **particle-logo-aggregate / 粒子聚合成 logo** 【高频】—— 光粒子/几何块先散后聚，拼成品牌 logo 落版。
   - Vivo（85s）、AGIC（105s）、Framer（68s）、蚂蚁（105s）、平安（134s 奖项 logo）
3. **kinetic-type-to-ui-background / 大字退为背景** 【高频】—— 前景大字退到背景层做底纹，前景再升 UI。
   - 注意力抓取（1s/16s/21s）、creatoroly（0s/8s）、Bard（1s/16s）、Framer（37s）、平安（0s）
4. **device-frame-continuity / 设备框连续** 【高频】—— 同一手机/浏览器框内换内容，框不动。
   - 注意力抓取（10s/13s）、Vivo（14s/55s）、平安（12s/117s）、蚂蚁（10s/76s）、荣耀（9s/20s/32s）
5. **match-cut-color / 颜色章节** 【高频】—— 整屏背景色做章节标记，跨章时前景保留同色元素。
   - 注意力抓取（9s/23s）、creatoroly（6s/18s/32s）、Vivo（12s/36s/45s）、蚂蚁（96s）、Bard（6s）、平安（43s）
6. **shared-element-state / 共享元素换状态** 【高频】—— 同一 pill/按钮/角色跨镜存在，只换内部状态。
   - 注意力抓取（5s pill）、Bard（20s pill）、荣耀（5s pill/45s orb）、creatoroly（24s polaroid）、Framer（18s 气泡）、蚂蚁（57s 男孩）
7. **cross-dissolve / 叠化** 【高频】—— 所有长片章节切换均有，不重复列举。
8. **particle-figure-assemble / 粒子聚合成人形** 【高频】—— 光粒子聚合成角色/跑者人形。
   - 蚂蚁（66s 金跑者）、AGIC（84s 黑洞→人）、Framer（36s 粒子→字）
9. **camera-orbit / 环绕运镜** 【高频】—— 镜头绕中心物体环绕，背景连续变化。
   - Vivo（63s 3D 演播厅）、平安（98s 迷宫）、蚂蚁（136s W logo）
10. **screen-record-punch / UI 录屏钻取** 【高频】—— 光标/指针在录屏内画框/指点，钻到详情。
    - 注意力抓取（13s）、Bard（20s）、Framer（18s）、蚂蚁（57s）

## 三、风格差异小结

本分片 10 个视频可分三档：

1. **极简 UI 演示档**（设计工作室 5.8s / 荣耀 69s / Bard 35s / Framer 75s）：白底或深色底，手机/浏览器框为主体，转场靠共享元素（pill、按钮、光标）和叠化，信息层级清晰，节奏慢，适合直接迁移到产品功能片。
2. **MG showreel 档**（creatoroly 45s / Vivo 90s / 平安知鸟 150s / 蚂蚁 153s）：章节化大色块，IP 角色/3D 元素反复出场，转场靠颜色翻章、粒子聚合、形状形变，节奏快，适合年度盘点/品牌片。
3. **电影感叙事档**（AGIC 111s / 注意力抓取 25s）：深色科技感，辉光/漏光/速度斜坡为主，转场服务情绪而非信息，部分为灵感参考。

**跨片最值得复用的 5–8 个 Pattern**（详见回报）：
- persistent-pill-and-orb（荣耀）—— 多用途演示不切黑
- floating-ai-bubble-over-canvas（Framer）—— AI 编辑可视化
- ui-flip-to-isometric-city（平安）—— 界面→数字生态
- nested-rect-tunnel-award-reveal（平安）—— 奖项/荣誉仪式
- touch-screen-flash-to-character（蚂蚁）—— 品牌开场穿屏
- ui-panel-spiral-tunnel（蚂蚁）—— 进入数字深处
- logo-orbit-across-landscapes（蚂蚁）—— logo 多场景展示
- letter-scramble-assemble（Bard）—— 品牌新词登场
