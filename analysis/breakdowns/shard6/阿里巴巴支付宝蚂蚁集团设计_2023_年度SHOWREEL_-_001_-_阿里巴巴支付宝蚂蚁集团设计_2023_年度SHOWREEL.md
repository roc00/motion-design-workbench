# 阿里巴巴支付宝蚂蚁集团设计 2023 年度 SHOWREEL

## 基础信息
- 类型：互联网大厂设计年度 showreel（支付宝/蚂蚁）
- 风格：3D 卡通 IP + UI 录屏 + 节日插画 + 实拍级 3D 场景混合，蓝主色，高能量蒙太奇
- 适用场景：大厂设计团队年度盘点、产品矩阵展示、品牌 IP 故事化
- 时长 / 大致镜头数：153.2s / cuts 56 个，约 70+ 镜头

- 0–8s：桌面显示器显示"支"字→手触碰屏幕→屏幕径向光爆→白闪→3D 卡通男孩 IP 从光中飞出落到舞台，"2023 Showreel"。

- 48–58s：小人矩阵→三手机季节主题→云电脑→卡通男孩穿过 UI 面板。
- 59–70s：男孩翻转入 UI 螺旋隧道→白闪→城市夜景飞行→金色粒子跑者成形。
- 72–82s：莲花体育场夜景→三手机太空主题。

## 动势
- 手触屏幕→男孩飞出（0–6s）：Z 轴先推近屏幕（Fast Push），白闪，男孩从中心飞向镜头（Slow Pull Out）。Easing ease-in-out。Feeling Cinematic / Premium。
- 螺旋隧道（59–64s）：镜头 180°旋转 + UI 面板卷成隧道，ease-in。Feeling Dynamic / Cinematic。
- W logo 环绕（134–140s）：镜头匀速环绕 logo，背景 cross-dissolve。Easing 线性。Feeling Premium。

## 空间与布局
- 全片以 3D 卡通男孩 IP 为叙事引导：他从屏幕飞出、穿过 UI、翻转成隧道、最后伸手收束；UI 面板始终作为"数字空间"的母题反复出现。

## 可沉淀的 Pattern 候选
1. **touch-screen-flash-to-character**：手触碰显示器 logo→屏幕径向光爆→白闪→角色从光中飞出（0–6s）。解决：品牌开场，把"产品"和"角色"用一次穿屏连接。
2. **ui-panel-spiral-tunnel**：角色行走在 UI 面板墙前，镜头翻转，UI 面板卷成螺旋隧道，隧道收敛白闪（59–64s）。解决：抽象"进入数字世界深处"。
3. **particle-figure-assemble**：城市光轨中的金色粒子聚合成人形跑者（64–68s）。解决：把抽象"速度/能量"具象成人。
4. **logo-orbit-across-landscapes**：品牌 logo 居中不动，镜头环绕，背景从云海 cross-dissolve 到沙漠再到草原（134–140s）。解决：品牌 logo 多场景适配展示。
5. **clone-multiply-character**：一个 Q 版角色复制成矩阵排列（45–50s）。解决：表达"规模化/集合"。
6. **character-walk-through-ui-wall**：角色在漂浮的 UI 面板墙中行走/穿行（57s / 144s）。解决：把 UI 界面变成可穿行的空间。
