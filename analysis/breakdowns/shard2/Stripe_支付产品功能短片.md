# Stripe 支付产品功能短片.gif

## 基础信息
- 类型：产品宣传 / 品牌片（3D 渲染 UI 产品合集）
- 风格：极简留白 + 3D 写实渲染的 UI 画廊；Stripe 紫 + 明黄/橘色家具点缀
- 适用场景：SaaS/支付类产品功能合集片，把多个 UI 模块装进一个"展厅空间"依次亮相
- 时长 / 大致镜头数：12.8s；cuts.txt 报 7 个硬切点（0.8 / 6.3 / 7.1 / 7.9 / 8.6 / 9.4 / 10.1），约 8–10 个镜头

## 镜头结构
开场（0–1s）白底手机结账表单 UI 直接淡入，随即背景沉入深蓝；中段（1–6s）镜头在一个三维"卡片展厅"里平移/环绕，多块产品卡片（图表、椅子商品图、$200 商品卡、手机文案卡）以不同景深漂浮排布，相当于把功能矩阵摊开成空间；随后（6–10s）镜头穿过几个实物化产品小品——橘色波点椅上立手机、笔记本桌面、米色显示器、紫色渐变手机场景，每个小景只停留约 1s；结尾（10–12s）落到一面黑板式"stripe"屏幕的 3D 房间，最后收束为紫色地球 logo 落版。
典型单镜 0.8–1.3s，整体是"长镜空间穿行 + 段尾硬切换景"的混合节奏。

## 动势（挑 2–4 个最典型转场写）
- Movement：Z 轴后拉 + 横移（1→2s），卡片由中心向四周展开
- Timing：Slow Reveal 起手，展完后以稳定速度横移浏览
- Easing：ease-in-out，空间展开带轻微弹性
- Feeling：Premium / Cinematic（展厅感、奢侈品橱窗节奏）

- Movement：设备小品之间的串联是硬切，但每个小景内有轻微推近
- Timing：Fast Start 换景、Slow Reveal 读 UI
- Easing：ease-out 落定
- Feeling：Technical / Premium

## 空间与布局
全片把"功能矩阵"物解成一个三维展厅：所有 UI 卡片、设备小品共享同一深蓝/紫色光环境，镜头只做平移与推近，信息层级随镜头远近变化——近处的设备特写承担具体功能文案，远处漂浮卡片承担"还有更多"的数量暗示。前后空间不靠剪辑硬接，而靠"同一空间换展品"维持连续。

## 可沉淀的 Pattern 候选
- **ui-gallery-parallax-drift**（UI 展厅视差漂移）：把多个产品 UI 卡片放进同一三维空间，镜头沿 Z 轴后拉并横移浏览，卡片按景深错位漂移。时间戳 1.0→5.0。解决"一次展示多个功能模块又不想做碎片快切"的叙事问题——把集合感交给空间而不是剪辑。
- **device-thumbnail-chain**（设备小品串联）：用手机/笔记本/显示器作为统一的"UI 承载框"，每个小景换一台设备、桌面道具随之更换，硬切但设备语言一致。时间戳 6.3–9.4。解决"多个设备端功能并列展示"时如何不显零散。
- **color-veil-cut**（色彩幕布藏切）：让前一镜主色（紫）铺满全屏，再从同色背景里浮出下一镜，用色彩而非转场特效做切点。时间戳 7.9→9.0。解决两段不同场景间需要平滑品牌过渡。
- **brand-globe-endcard**（品牌地球落版）：展厅最后推到品牌标识物并退成纯色地球 logo。时间戳 11.0→12.0。属通用结尾，价值低，仅记录。
- 注：3D 家具渲染质感属美术资产层面，不是可程序化 Pattern，标灵感参考。
