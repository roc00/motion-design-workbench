# flowith 1.0 正式版本！时隔 4 个月的大更新 - dereknee

## 基础信息
- 类型：App 发布 / AI Agent 产品片（玻璃拟态 3D 卡片演示）
- 风格：浅灰纹理桌面 + 玻璃拟态卡片、虹彩球、柔和投影；高端科技感
- 适用场景：AI Agent / 工作流产品发布，演示"AI 边思考边产出一系列结果卡"
- 时长 / 大致镜头数：94.3s；cuts.txt 报 9 个硬切点，大量是卡片间的无缝漂移

## 镜头结构
开场（0–7.2s）黑场 flowith logo → 虹彩玻璃球在同心圆环上旋转放大，成为产品图腾；10.8–25.2s 搜索胶囊里逐字敲入"去巴黎三天"类问题，玻璃卡片依次滑入，卡上文字逐段浮现、与用户对话追问偏好；27–34s "Your Goal"目标清单卡、"Oracle is thinking…"思考胶囊；36–61s 是答案卡群逐个生成：巴黎照片卡、地图卡、行程文本卡、奥运赛事卡、4 日行程长卡；63–70s 清单上绿色对勾逐个点亮；72–79s "Contact Mistral AI team?"确认卡→Send/Cancel 按钮→"Email Sent!"反馈胶囊；82.8–84.6s 关键运镜：镜头大幅后拉，所有卡片在三维空间中铺开成一个工作流画廊；86.4–91.8s 黑场"AI for deep work"→www.flowith.io 落版。
节奏：前半段卡片依次生成（慢），后半段后拉揭示全景（收）。

## 动势（挑 2–4 个最典型转场写）
- Movement：后拉揭示（82.8→84.6），从单卡特写急速后拉至全景画廊
- Timing：前慢后快，后拉时有一刹"展开"
- Easing：ease-in-out，后拉带轻微加速
- Feeling：Cinematic / Premium（揭示感、顿悟感）

- Movement：卡片滑入堆叠（36→48），新卡从侧面滑入并微微下压叠放
- Timing：Slow Reveal，每张间隔约 2s
- Easing：ease-out
- Feeling：Premium / Calm

## 空间与布局
全片在一个"虚拟工作台"上组织：任务以卡片为单位，卡片在桌面上倾斜、堆叠、漂移，镜头始终在卡片之间平移。信息层级是"输入卡→目标卡→思考态→结果卡群→确认卡→成功反馈"，最后用一个后拉镜头把时间线上的过程物解成空间中并存的卡片群——把"AI 工作流"从时间叙事翻译成空间陈列。

## 可沉淀的 Pattern 候选
- **workflow-cards-pull-back**（工作流卡片后拉揭示）：前段特写逐张生成结果卡，结尾镜头大幅后拉，把时间线上先后出现的所有卡片同时展现在三维空间中，形成"一次任务的全貌画廊"。时间戳 82.8→84.6。解决"AI 过程是线性的，如何给观众一个整体顿悟"。
- **glass-card-state-grow**（玻璃卡状态生长）：同一张空白玻璃卡经历"空白→逐字对话→清单→按钮→成功胶囊"的状态演化，不换容器只换内容。时间戳 16.2→19.8、72→79。解决"用一张卡承担一个交互闭环"。
- **orble-loading-recur**（虹彩加载图腾复现）：开场的虹彩球/圆环在中段"Oracle is thinking"处复现为加载态。时间戳 1.8→7.2、28.8→30.6。解决"让产品图腾同时承担品牌与加载反馈"。
- 与 ISUX 片同属"纸面卡片"语言，但本片多了 3D 后拉画廊这一强 Pattern。
