# Conduit AI 助手产品发布视频

## 基础信息
- 类型：App 发布 / 产品宣传（创始人出镜 + 产品 UI 录屏穿插）
- 风格：真实人物出镜（办公室/酒店大堂实景）+ 玻璃拟态 UI；品牌绿散景
- 适用场景：B2B AI 助手类产品发布片，"创始人讲卖点 + 录屏证明"结构
- 时长 / 大致镜头数：33.3s；cuts.txt 报 5 个硬切点，实际画面切换更密（人物/UI/字卡交替），约 15+ 镜头

## 镜头结构
开场（0–2.6s）"Hospitality"字卡配合漂浮的酒店照片碎片，碎片汇聚成一张酒店建筑照片；随后（2.6s）绿色散景上" Travellers expect instant responses"；3.9–5.2s 创始人正面出镜介绍；6.5–11.7s 进入左右分栏：左侧竖排"Reply / Research / Memorize"能力清单，右侧手机聊天/订房 UI，光标点选高亮房态；13–14.3s 回到创始人，身旁浮起 Customer/Sales/Finance/Support 圆形标签；15.6–20.8s 是统一收件箱的屏幕录制，光标点开对话、点"Escalate to me"升级；22–26s 字卡"Behind every guest facing agent is…"→星号 Operator logo→星号周围环绕各 App 图标；27.3–28.6s 创始人收尾；29.9–31.2s 绿色散景落版"Start today at conduit.ai"。
节奏：讲卖点段落用分栏停留，证明段落用屏幕录制，人物/UI 之间靠硬切。

## 动势（挑 2–4 个最典型转场写）
- Movement：照片碎片聚合（0→1.3s），碎片从四周向中心收拢
- Timing：Slow Reveal，先散后聚
- Easing：ease-in，收拢末尾减速
- Feeling：Premium / Cinematic

- Movement：左右分栏（5.2→6.5s），手机气泡右移、左栏文字滑入
- Timing：Fast Start 建立分栏，随后静止读内容
- Easing：ease-out
- Feeling：Technical

## 空间与布局
全片在三个空间间往返：人物实景（创始人）、概念分栏（文字清单）、产品录屏（真实 UI）。衔接靠"元素跨空间变形"——能力词从字卡变悬浮圆标（11.7→13）、聊天气泡从人物旁变分栏右半（5.2→6.5），让硬切不显跳。信息层级是"主张→证明→落版"，每段用不同空间承担。

## 可沉淀的 Pattern 候选
- **split-text-device-bracket**（文字-设备分栏夹持）：左侧竖排能力词清单，右侧手机/设备 UI 演示同一批能力，人物旁的小气泡可作为分栏的来源锚点。时间戳 5.2→11.7。解决"嘴上讲能力、手上要证明"的并列表达。
- **floating-label-orbit**（悬浮标签环绕人物）：讲完概念后，关键词不消失，而是变成悬浮圆形标签环绕人物漂浮。时间戳 11.7→14.3。解决"让抽象能力可视化地围在创始人身边"。
- **logo-hub-convergence**（logo 枢纽聚合）：结尾把品牌符号（星号/星芒）放大成 hub，第三方 App 图标环绕飞入。时间戳 24.7→26.0。解决"产品连接了哪些生态"的一句话视觉化。
- **cursor-drill-escalate**（光标钻取升级）：屏幕录制中光标先点列表条目钻进详情，再点"升级/转交"按钮完成动作。时间戳 16.9→20.8。属 ui-drill-in + cursor-carry 的组合，解决"演示一个完整交互闭环"。
- 创始人出镜表演本身属灵感参考。
