# 优秀作品 - 不具名动画师

## 基础信息
- 类型：角色 IP 片 / 扁平 MG 动画（Duolingo 风格品牌短片）
- 风格：2D 扁平矢量、高饱和撞色（蓝/黄/紫）、角色萌系叙事
- 适用场景：教育/工具类 App 的品牌叙事短片，用角色冒险串起产品卖点
- 时长 / 大致镜头数：24.8s；cuts.txt 报 22 个硬切点，镜头切换极密（约 1–2s 一镜）

## 镜头结构
开场（0–2s）一只手举着显示埃菲尔铁塔的手机，随后三块手机屏并排，角色凑近观看；2–4s 关键段：手机屏像门一样翻开，角色和绿色猫头鹰穿过手机屏进入下一场景；5–10s 是一场"旅程蒙太奇"——地图公路、购物车、山坡踏板车，最终 10s 处揭示：这条"路"其实是一根被巨手拉扯的面条；11–13s 夜间城市吃面场景后，13s 起回到双手机屏；14–16s 整屏变成 App 图标矩阵，角色在图标间穿行；17–18s 镜头推进俄式宫殿窗户；19–21s 木箱/热气球/日文字符卡片堆叠；22–24s 猫头鹰钻入手机框、最后群像角色 + 品牌猫头鹰落版。
节奏：高密度短镜快切，但靠共享元素（手机、路/面条、图标矩阵）维持连贯。

## 动势（挑 2–4 个最典型转场写）
- Movement：手机屏翻转开门（2.0→4.0），门扇左右滑开，角色向前 Z 轴穿过
- Timing：门开 Fast Start，穿行匀速
- Easing：ease-in-out，开门略带弹性
- Feeling：Playful / Cinematic（冒险片节奏）

- Movement：路→面条（8.0→10.0），黄色曲线先随踏板车向前，再被手向上拎起
- Timing：前半段行进，揭示瞬间 Slow 拉远
- Easing：ease-out（揭示减速，给观众反应时间）
- Feeling：Playful（笑点揭示）

## 空间与布局
全片空间靠"同一轮廓/同一母题在两个场景间被重新定义"维持：手机矩形既是屏幕又是门洞（2–4s），网格既是 App 列表又是城市街区（14–16s），一条曲线既是公路又是面条（8–10s）。信息层级不随剪辑跳，而是随"揭示"逐层翻转——先当产品 UI 看，再发现它是世界。

## 可沉淀的 Pattern 候选
- **device-frame-as-portal**（设备框变门洞）：把竖版手机屏绕中轴翻转/滑开，角色或镜头直接"穿过屏幕"进入下一场景。时间戳 2.0→4.0。解决"从产品界面世界进入使用场景世界"的无缝跨越，比硬切进入更有叙事感。
- **shared-line-reveal-morph**（共享曲线揭示形变）：前一镜的一条功能性线条（公路/路径）在后一镜被拉远揭示成完全不同的物体（面条/河流），形状曲线连续。时间戳 8.0→10.0。解决"用一个视觉双关把功能卖点（学习路径）和情绪点（美食/旅行）缝合"。
- **ui-grid-becomes-environment**（UI 网格变环境）：App 图标/卡片宫格的布局被镜头推近，结构完全匹配地生长成可穿行的街区/房间。时间戳 13.0→16.0。解决"把产品功能列表空间化、给集合感"。
- **window-zoom-through**（窗户/门洞推穿）：沿建筑窗户或门框中轴推近，穿过矩形洞口进入室内。时间戳 17.0→18.0。与 zoom-through 同族，强调"矩形洞口"这一锚点。
- 角色表演、表情、配音笑点均属灵感参考，不进 Pattern。
