## 2. Pattern 候选按频次排序（≥2 个不同视频标「高频」）

1. **card-stack / card-fly-in 卡片飞入堆叠**（高频）：Stripe 1.0–5.0、Conduit 11.7–14.3、flowith 36–48、TME 69–71/73–75、饿了么 16.2、ISUX 21.6–52.2。机制：多枚卡片/UI 块以不同景深从四周飞入、错落叠放。解决"多结果/多套餐的集合陈列"。
2. **parallax-push / pull-back-reveal 视差推进与后拉揭示**（高频）：Stripe 1.0–5.0、flowith 82.8–84.6、TME 276–279、饿了么 91.8、Similarweb 15.6。机制：Z 轴后拉把线性过程物解成空间画廊。解决"从单特写顿悟全貌"。
3. **kinetic-type-match 同版式字卡换字**（高频）：Similarweb 0–9.1/26、ISUX 0–5.4、TME 5.0–7.0/章节卡、饿了么 5.4。机制：固定字卡版式上整句替换、关键词跳色/扫亮。解决"排比卖点/章节分隔"。
4. **glow-light-transition / color-veil 光与色彩幕藏切**（高频）：Stripe 7.9、Similarweb 10.4/15.6、Waytoagi 1.3、TME 75–77、flowith 1.8。机制：用主色铺满或发光体衔接两段不同场景。解决"不同场景间的品牌色过渡"。
5. **bookend-shared-element 首尾共享元素闭环**（高频）：Waytoagi 花 logo（1.3/58.5/61）、TME 绿球↔绿气泡（12/279）、flowith 虹彩球↔加载态（1.8/30.6）、ISUX 搜索胶囊（5.4/81）、饿了么笔画↔手写 logo（5.4/109）。机制：同一符号在开场、中段道具、落版三次出现。解决"抽象产品片的情感锚点"。
6. **device-frame-continuity 设备框内换内容**（高频）：Stripe 6.3–9.4、Conduit 11.7、ISUX 25.2、不具名 2.0、TME 96–106。机制：手机/笔记本/显示器框不变，只换屏内内容。解决"多端功能并列"。
7. **cursor-carry / screen-record-punch 光标引导录屏**（高频）：Conduit 7.8–20.8、Similarweb 15.6–24.7、ISUX 7.2、flowith 10.8。机制：真实光标在 UI 上点选、钻进详情。解决"证明真实可操作"。
8. **paper/glass-card-workspace 纸面玻璃卡片工作台**（高频）：ISUX 21.6–52、flowith 全程、Stripe 1.0–5.0。机制：把结果卡放浅白/玻璃"桌面"上漂移、倾斜、堆叠。解决"AI 多结果的轻盈陈列"。
9. **section-card-respell 章节卡套版**（中频）：TME 7.2/160.8/218.4/249.6、饿了么丝带段。机制：同模板蓝图/丝带换字。解决"合集片章节分组"。
10. **spotlight-reveal 追光圈揭示 UI**（低频，强特征）：Similarweb 15.6–24.7/32.5–36.4。机制：暗色仪表盘上只留跟随光标的圆形光圈。解决"复杂录屏只让一个数据点被读"。
11. **type-to-glyph-to-graphic 字→光→图形**（低频）：Similarweb 10.4–14.3、TME 3.6–5.0。机制：关键词拖出光收成品牌图形。解决"文字论点到图形证据的桥"。
12. **device-frame-as-portal 设备框变门洞**（低频）：不具名 2.0–4.0。机制：手机屏翻开门洞穿行。解决"界面世界到使用场景的跨越"。
13. **workflow-cards-pull-back 工作流后拉画廊**（低频，flowith 独有强 Pattern）：82.8–84.6。
14. **blade-fold-logo-assembly 扇叶折拼 logo**（低频，TME 66.5–69）。
15. **card-tunnel-travel 卡片队列穿飞**（低频，TME 73–75）。
16. **toast-stack-displace 通知堆叠让位**（低频，X Toast 全程，组件级）。
17. **code-emerges-world 代码长出场景**（低频，Waytoagi 11.7–14.3）。
18. **bookend-logo + container-lid-burst 开盖喷粒子**（低频，Waytoagi）。

## 3. 风格差异小结

- **轻量留白派**（ISUX、flowith、Stripe）：近白/玻璃桌面、卡片漂浮、慢叠化、几乎无硬切——适合 AI 助手/搜索类，气质是"高级、可信、不打扰"。
- **深色科技派**（Similarweb、饿了么后段、TME 金段）：深蓝/暗黑 + 青色或金色高光 + 聚光/全息，强调"数据之光"与"金属 premium"。
- **高饱和蒙太奇派**（不具名、Waytoagi、饿了么/TME showreel）：撞色、快切、角色/像素/体素叙事，靠共享元素与同构图模板维持连贯——适合品牌/活动片。
- **出镜+录屏派**（Conduit）：真人讲卖点、分栏证明、屏幕录制，靠"气泡/标签跨空间变形"缝合人物与 UI。
- 跨片最值钱的通用语言是：**卡片工作台 + 后拉揭示 + 首尾共享元素 + 字卡套版**，这四条在轻量派与 showreel 派中反复出现，最值得进 Framework。
