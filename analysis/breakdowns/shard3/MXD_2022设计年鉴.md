# MXD 2022设计年鉴（腾讯视频设计）

## 基础信息
- 类型：设计 Showreel（腾讯视频 MXD 年度年鉴）
- 风格：深色 UI 底 + 高饱和品牌色（橙绿蓝），UI Demo 与 3D/实拍混剪
- 适用场景：视频/流媒体产品的设计年鉴、品牌活动包装、UI 组件集锦。开场与收尾的「品牌色条」贯穿手法尤其可借鉴。
- 时长 / 大致镜头数：128s，cuts 62 个，估算 60+ 镜；快切蒙太奇，单镜 ~2s。

## 镜头结构
- 开场（0–8s）：MXD 字标在网格上淡出 → 一条橙绿蓝分段色条生长 → 色条变成播放器进度条，视频画面从条上方升起，完成「品牌→产品」的无缝引入。
- 中段（8–115s）：按业务板块快切——长视频播放器 UI、NBA/体育板块、直播 LIVE、草场地 VIP、V视频活动、数字人、角色设计、音频 KMS 等，段间多硬切，段内有自己的小运镜。
- 收尾（115–128s）：Audio Design KMS → MXD Express → 照片墙（真人把照片贴上墙，拼出 MXD 字标）→ MXD 落版。
- 节奏：快切蒙太奇为主，开场与收尾各有一条连续运镜。

自造标签：
- color-bar-carousel：同一组垂直品牌色条在不同场景（抽象图形→舞台大屏→走廊海报→文字卡→实物麦克风）之间连续旅行，纹样不变只换载体（62.5–67.5s）。
- bar-to-player：一条抽象分段色条逐步长出拖块、播放控件、视频画面，5 秒内从图形进化成完整播放器（3.6–8.0s）。

## 动势（挑最典型）
- **bar-to-player（3.6–8.0s）**
  - Movement：水平向（色条生长）+ 垂直向（控件上下长、视频向上滑入）。
  - Timing：Slow Build（条生长慢）/ 控件快出 / 视频滑入中等速度。
  - Easing：条生长 ease-out，控件弹性 spring。
  - Feeling：Technical / Premium。
- **color-bar-carousel（62.5–67.5s）**
  - Movement：垂直向（竖条展开）+ 场景间硬接。
  - Timing：每换一个载体 ~0.8s。
  - Easing：ease-in-out。
  - Feeling：Dynamic / Playful。

## 空间与布局
- 开场 bar-to-player 以水平色条为中轴，控件上下对称生长，视频填入条上方，形成「底轴固定、上内容填充」的播放器标准构图。
- color-bar-carousel 不依赖空间连续，而靠「竖条纹样」这一视觉锚点跨场景旅行，构图每次都是竖条满屏，换的只是载体材质。

## 可沉淀的 Pattern 候选
1. **bar-to-player**：先用一条抽象分段色条建立品牌节奏，再在同一条色条上长出拖块、控件、视频画面，5 秒内把「图形」进化成「播放器」。证据 3.6–8.0s。解决「品牌开场→产品 UI」的无缝引入，避免 logo 与界面两张皮。
2. **color-bar-carousel（品牌纹样旅行）**：锁定一组高饱和垂直色条作为品牌母题，让它在抽象图形→舞台大屏→海报→文字卡→实物道具之间连续变形，载体全换纹样不变。证据 62.5–67.5s。解决「一个品牌色如何在多场景活动包装中保持识别」。
3. **photo-wall-endcard**：真人/手把一张张照片贴上墙，最终拼出品牌字标，再收敛成标准落版。证据 117–126s。解决「年度/合集片的情感收尾」，用手工感替代直接 logo。
4. **clone-multiply-grid**：单张缩略图/角色图复制成整墙矩阵，再缩成小设备。证据 10.8–12.6s、102.6–106.2s。解决「展示内容库数量感」。
- 灵感参考：3D 球员带电光、数字人、舞台实拍本身为单段炫技，不候选。
