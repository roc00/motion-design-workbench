# 快手2022设计年鉴（KWAI LIVE SHOWREEL）

## 基础信息
- 类型：设计 Showreel（快手直播/礼物/活动 UI）
- 风格：高能量霓虹赛博朋克 + Q 版卡通，高饱和紫粉蓝，大量辉光与 3D
- 适用场景：直播/社交/娱乐产品的设计年鉴、活动包装、礼物/虚拟道具展示。开场虫洞运镜可直接借鉴。
- 时长 / 大致镜头数：89.6s，cuts 55 个，估算 50+ 镜；快切 + 长运镜混合。

## 镜头结构
- 开场（0–9s）：黑场帽子剪影 → 霓虹城市，建立 KWAI LIVE 世界观。
- 章节引入（9–20s）：「2022 KWAI LIVE SHOWREEL」字标 → 霓虹矩形虫洞推进 → 爆点星芒 → 穿进卡通城市街道。
- 中段（20–82s）：按板块快切——飞车穿城、金色神像/神鞋、三手机虚拟形象、仙鹤宫殿、沙漠卡车、礼物设计（Q 版道具）、礼物面板 UI、手机矩阵、38 城堡、年度奖牌等。
- 收尾（82–88.2s）：小人走进红色门洞 → 城市光柱爆点 → 快手 logo 落版。
- 节奏：高能量蒙太奇，开场与收尾各有一条连续 Z 轴运镜。

- neon-wormhole-burst：霓虹同心矩形虫洞推进到中心 → 爆成径向星芒 → 星芒散开露出新场景（14.4–19.7s），三段一镜。

## 动势（挑最典型）
- **neon-wormhole-burst（14.4–19.7s）**
  - Movement：Z 轴持续推进（虫洞）→ 中心收敛 → 径向炸开 → 再次 Z 轴进入新街道。
  - Timing：Slow Build（虫洞 ~2.5s）/ Fast Burst（爆点 ~0.5s）/ Slow Reveal（街道 ~1s）。
  - Easing：虫洞 ease-in（越推越快），爆点 ease-out，街道 ease-out。
  - Feeling：Dynamic / Cinematic。
- **light-burst-endcard（84.6–88.2s）**
  - Movement：中心光柱向上炸开再向中心收缩。
  - Timing：Fast Burst / Slow Contract。
  - Easing：ease-out then ease-in。
  - Feeling：Premium。

## 空间与布局
- 虫洞段用同心矩形的透视灭点把视线锁死在中心，所有边框朝中心后退，制造「穿越」错觉；爆点以中心为原点径向发散，新场景从中心长出。收尾与开场同构：都从一个中心光点起/收。

## 可沉淀的 Pattern 候选
1. **neon-wormhole-burst**：多层同心矩形/圆框后退形成虫洞，镜头推进到中心后爆成径向星芒，星芒散开露出新场景。证据 14.4–19.7s。解决「两个完全不同板块之间的强能量过渡」，比硬切更有仪式感。
2. **burst-to-scene（星芒揭示）**：径向光线从中心炸开后散开，光中浮现新场景，车辆/主体沿光道驶入。证据 18.0–19.7s。解决「从抽象光效到具体 3D 场景」的落地。
3. **doorway-occlusion（门洞藏切）**：角色走向一个门洞/遮挡物，物体挡满画面藏切到新场景。证据 82.8s。解决「角色叙事段之间的自然遮挡」。
4. **clone-multiply-phone-grid**：单部手机复制成整墙网格再缩回单排。证据 54.0–57.6s。解决「展示 UI 位/礼物位数量」。
5. **light-burst-endcard**：中心光柱炸开后向中心收成品牌 logo。证据 84.6–88.2s。解决高能量片的收尾。
- 灵感参考：金色神像/神鞋、仙鹤宫殿、Q 版礼物道具的 3D 渲染本身为单段炫技，不候选。
