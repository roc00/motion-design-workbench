## 二、Pattern 候选（按频次排序，≥2 个不同视频标「高频」）

### 高频（跨 ≥2 个视频）
1. **clone-multiply-grid（单元素复制成矩阵再缩回）** — 高频
   - MXD 10.8–12.6、102.6–106.2；快手 39.6–41.4、54.0–57.6；腾讯 45.0–50.4。
   - 机制：单张缩略图/角色/手机复制成整墙网格，再缩回单排，表达「内容库/皮肤/礼物位数量感」。
2. **cursor-carry-as-transition（光标的真实操作即转场）** — 高频
   - Gemini 20.8–23.4（拖滑块）、24.7–28.6（点卡片）、37.7–40.3（切开关）；元意空间 11.0–14.0（打字/点 Ask Gemini）。
   - 机制：手型光标拖、点、切，每次操作把当前 UI 带入下一状态，转场=交互。
3. **starburst/light-flare-section-marker（星芒/辉光爆点做章节点）** — 高频
   - 快手 17.0–19.7（虫洞爆点→街道）、84.6（光柱→logo）；元意空间 5.0/7.0/10.0（四角星芒）；Google AI 52.2、63.0（发光圆环呼吸点）。
   - 机制：在深/浅背景之间用一个中心爆点/星芒作章节分隔，颜色随段变化，比硬切有节奏。
4. **object-assembly-logo / letters-to-toolbar（字母/图标聚合成品牌或工具栏）** — 高频
   - Microsoft 365 3.9–6.5（app 图标聚合成 365 logo）；元意空间 0.0–5.0（logo 字母变图标成工具栏）。
   - 机制：品牌名里的字母或产品图标逐个形变/飞入，聚合成主 logo 或一条工具栏，再携带进后续场景。
5. **shared-element-shape-morph（同形不同物跨镜，载体换内容不换）** — 高频（贯穿全部分片）
   - 阿里 4.6–5.4（海报→手机）、腾讯 16.2–25.5（字母→键帽）、Microsoft 12.5–19.5（道具→UI）、Dia 2.0–6.5（太阳→输入框）、Google AI 32.4–34.2（波形→搜索栏）。
   - 机制：锁定一个形状/内容作锚点，前后镜只换载体材质，形状与位置几乎不动。

## 三、风格差异小结

- **设计 Showreel（阿里/MXD/快手/腾讯）**：快切蒙太奇为主（cuts 31–194），靠「子品牌自带配色」分段；真正可复用的机制集中在单段首尾的「品牌字标拆解」（阿里 1688 数字、腾讯字母变键帽）和收尾落版（MXD 照片墙、快手光柱）。
- **Google 系 AI 产品片（Google AI / Gemini Canvas / 元意）**：深色负空间 + 流体辉光 + 一镜到底 UI 漫游（cuts 0–1），靠「光标操作、文字打散、辉光翻色、波形」做衔接，几乎不用硬切。
- **实体/角色/3D 产品片（蜜雪、Microsoft 365）**：一个连续 3D 世界，靠「同形不同物」把原料/道具/UI 焊成一条内容线。
- **短着陆片（Dia）**：极简，用一个圆形母题完成「天体→产品核心交互」的全片隐喻。
- 共性：跨片反复出现的不是硬切，而是 **shared-element（同形锚点）+ glow/flare（光作章节）+ cursor/字卡（注意力引导）** 三类；这正是框架现有 30 卡偏「UI 组件动效」所缺的「镜头级衔接语言」。
