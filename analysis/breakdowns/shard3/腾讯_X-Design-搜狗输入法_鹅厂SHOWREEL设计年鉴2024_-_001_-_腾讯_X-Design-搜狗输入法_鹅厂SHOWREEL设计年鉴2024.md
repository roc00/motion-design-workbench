# 腾讯 X-Design 搜狗输入法 鹅厂 SHOWREEL 设计年鉴 2024

## 基础信息
- 类型：设计 Showreel（搜狗输入法/X-Design）
- 风格：浅色极简 + 品牌绿（搜狗绿），字体/按键/吉祥物三段式，干净产品感
- 适用场景：输入法/工具类产品设计年鉴，尤其「字体→按键→界面」的字体驱动转场可直接借鉴。
- 时长 / 大致镜头数：72.8s，cuts 31 个，估算 30+ 镜；UI 段节奏中等，吉祥物段偏快。

## 镜头结构
- 开场（0–7s）：3D 彩色字母 S → 汪仔吉祥物 3D 形象 →「SOGOU 汪仔*」卡片。
- 字体段（7–25s）：汪仔奔跑 → 红色圆日 → 倾斜键盘 → 字体样张「SOGOU2024-TTF」→ 大字「分词」解构 →「QWER」字母解剖 → 字母拆成键帽拼成真实键盘。
- 功能段（25–66s）：键盘设置面板、双拼/手写/智能语句、键盘浮在影视剧上的创意输入、AI 聊天、皮肤/表情/吉祥物、手机双机展示。
- 收尾（66–72.8s）：动漫女孩 → 橙色 3D「S」+「SHOWREEL 2024」落版。
- 节奏：字体段慢而讲究（一镜到底的字形演化），功能段快切。

自造标签：
- letterform-to-keycap：大号字母先做解剖（构造线/填充），再把每个字母直接散成键帽，键帽排成真实键盘 UI（16.2–25.5s）。

## 动势（挑最典型）
- **letterform-to-keycap（16.2–25.5s）**
  - Movement：Z 轴（样张→大字）→ 局部拆解（偏旁/字母飞散）→ Z 轴拼回键盘。
  - Timing：Slow Build（字形解剖 ~5s）/ Fast Scatter（散键帽 ~0.5s）/ Medium Assemble。
  - Easing：拆解 ease-in，拼回 ease-out（键帽落位带轻微 spring）。
  - Feeling：Premium / Technical。
- **character-deconstruct（19.5–21.0s）**
  - Movement：字向四周炸开再合拢。
  - Timing：Fast Out / Fast In。
  - Easing：弹性。
  - Feeling：Playful。

## 空间与布局
- 字体段全程居中对称、大量留白，绿色只用于强调（分词二字、选中框），黑字承担信息。字形→键帽的转化靠「同形不同物」：字母在白底是排版字，飞散后落到灰底就成了有厚度的键帽，空间从平面排版变成 3D 键盘。

## 可沉淀的 Pattern 候选
1. **letterform-to-keycap（字形变键帽）**：先把字母做字体解剖（构造线、笔画高亮、开关），再让每个字母散成独立键帽，键帽排成真实键盘。证据 16.2–25.5s。解决「从品牌字体规范→产品界面」的无缝引入，用字母本身做桥梁。
2. **character-deconstruct（汉字解构）**：把一个汉字拆成偏旁几何块再拼回，配合「分词/拆解」语义。证据 19.5–21.0s。解决「产品功能=拆解/分词」的视觉化。
3. **font-specimen-to-product（样张到产品）**：从字体样张页（带字库、开关、字符表）钻进去放大成主视觉。证据 16.2–18.0s。解决「设计规范展示→产品」的衔接。
4. **keyboard-over-footage（键盘浮于影视）**：键盘从底部浮起叠加在影视剧画面上，表现「在任意内容上输入」。证据 36.0–41.4s。解决「输入能力跨场景」的演示。
5. **clone-multiply-keyboard**：一个表情/吉祥物复制成满键盘。证据 45.0–50.4s。解决「皮肤/表情数量」展示。
- 灵感参考：汪仔奔跑、3D 吉祥物表演为角色炫技，不另立机制。
