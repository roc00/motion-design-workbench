# NextLevel！2023阿里设计年度Showreel（10+业务设计团队成果集锦）

## 基础信息
- 类型：设计 Showreel（多团队年度成果混剪）
- 风格：高能量蒙太奇 + 子品牌段落风格各异（MG/3D 写实/UI Demo/角色 IP）
- 适用场景：大型设计团队年度回顾、多业务线成果合集、品牌子板块集锦。镜头语言本身偏「段落秀」，可借鉴的是子板块之间的章节切分与单段内的品牌拆解运镜。
- 时长 / 大致镜头数：203.6s，cuts 检测 194 个硬切点，估算 150+ 镜；平均单镜 ~1.2s，快切蒙太奇为主。

## 镜头结构
- 开场（0–6s）：白底字母碎块拼出「Alibaba Design」→ 黑底「Taobao SHOWREEL」章节字卡 → 红底淘宝大赢家卡通 IP 段，用三档黑白红配色快速定调。
- 中段（6–192s）：按业务线轮番上阵，每段 5–15s，子品牌自带配色与版式（1688 橙、饿了么蓝、钉钉粉蓝、UOO 紫等），段与段之间多用硬切/节拍切，段内有自己的小运镜。
- 收尾（192–203.6s）：HMI 驾驶模拟实验室段落，镜头沿 3D 环岛→穿门→室内→屏幕 UI→实拍实验台一路推进，最后横向运动模糊扫出「Alibaba Design」落版。
- 整体节奏：极快快切蒙太奇，单段内保留 1–2 个可读结果，段尾收束到子品牌字卡。

## 动势（挑最典型）
- **1688 数字拆解段（43.8–49.6s）**
  - Movement：Z 轴急推（1688→1），随后数字间水平方向糊动（1→6→8），最后 Z 轴拉出回 1688。
  - Timing：Fast Start（急推入数字）/ Hold（每数字停 ~1.5s 读注解）/ 快出（模糊带 ~0.3s）。
  - Easing：急推 ease-out，数字切换用线性模糊带 + 两端 ease-out。
  - Feeling：Premium / Technical。
- **收尾穿镜（196–200.5s）**
  - Movement：Z 轴连续推进，环岛→门→室内→屏幕。
  - Timing：Slow Reveal 持续匀速推。
  - Easing：ease-in-out，全程几乎匀速。
  - Feeling：Cinematic。
- **开场字母拼合（0–1.5s）**
  - Movement：从四周向中心汇聚。
  - Timing：Fast Start。
  - Easing：ease-out。
  - Feeling：Playful / Premium。

## 空间与布局
- 1688 段全程居中对称、橙底留白，数字占画面 70%，注解小字居右下，靠「同构图换数字」维持空间连续，信息层级只有大字+注解两层。
- 收尾穿镜是一条连续 Z 轴路径：3D 环岛（宏观）→ 门洞 → 室内（中景）→ 大屏 UI（微观），空间纵深用圆环发光线作为引导线，最后横糊切平到 2D 落版。

## 可沉淀的 Pattern 候选
1. **numeral-morph-roll**：品牌名拆成单个字符，在同色底上逐个 hold 一句注解，字符之间用横向运动模糊切换，最后拼回完整品牌名。证据 43.8–49.6s。解决「在 5 秒内把品牌名/版本号拆成多个卖点」的叙事问题——把 logo 本身变成章节容器。
2. **crash-zoom-into-character**：从完整字样急推放大到其中一个字符，其余字符滑出画面。证据 43.0–44.6s（1688→1）。解决「从字卡里抽出一个主角」的聚焦问题。
3. **fly-through-to-screen**：相机沿 3D 场景连续推进，穿过门/窗/物体后落到一块屏幕/UI 上，把「物理产品」和「其 UI」用一条 Z 轴焊死。证据 196.0–198.3s。解决「产品外观→界面功能」的空间跳转断裂。
4. **blur-rack-to-footage**：屏幕 UI 在推镜中失焦，实焦落到实拍使用场景，方向继承。证据 199.7–200.5s。解决「演示 UI→真实使用证据」的衔接。
5. **card-flip-poster-to-character**：海报/卡片绕轴翻面，背面露出新角色或新信息。证据 3.8–4.6s。解决「同一张卡片上正反两面信息」的翻页式揭示。
6. **motion-blur-swipe-endcard**：横向往运动模糊扫过画面，模糊带中切到品牌落版。证据 201.3–202.0s。解决段落/全片收尾的藏切。
- 灵感参考（不候选）：各业务线的 3D 写实产品渲染、卡通 IP 表演、实拍实验台镜头本身，均为单段炫技，不具跨片复用的程序化机制。
