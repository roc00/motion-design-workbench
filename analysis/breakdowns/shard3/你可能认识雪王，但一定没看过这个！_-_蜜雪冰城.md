# 你可能认识雪王，但一定没看过这个！（蜜雪冰城·青提雪王）

## 基础信息
- 类型：角色 IP 片 / 3D 产品宣传（蜜雪冰城青提新品）
- 风格：明亮 3D 卡通，高饱和青绿，梦幻海岛世界
- 适用场景：食品/饮品新品的角色 IP 宣传片；可借鉴的是「推近主角果实→变成杯中原物」的物件匹配切。
- 时长 / 大致镜头数：42.5s，cuts 21 个，实为一镜到底 3D 世界漫游；约 10 个场景。

## 镜头结构
- 开场（0–13s）：青提海岛全景，雪王披红披风飞、划船、过瀑布，建立梦幻世界。
- 中段（13–22s）：雪王被跷跷板弹起，飞向一颗巨大青提，镜头推入青提，青提化作杯中一杯青提饮品。
- 后段（22–39s）：雪王举冰淇淋+饮品，品牌合作卡「即梦AI×蜜雪冰城」，随后雪王乘青提火箭穿梭葡萄园、酒碗、彩虹等多个 3D 场景。
- 收尾（39–42.5s）：「阳光青提」产品海报落版。
- 节奏：长镜连续运镜，场景靠雪王飞行/镜头推进连接。

## 动势（挑最典型）
- **object-zoom-to-product（16.0–19.5s）**
  - Movement：Z 轴推入大青提 → 青提下落分解成杯中青提。
  - Timing：Slow Push（推青提 ~2s）/ Fast Drop（落杯 ~0.5s）。
  - Easing：推入 ease-in，落杯 ease-out。
  - Feeling：Playful / Premium。
- **雪王飞行段**
  - Movement：斜向上 + Z 轴。
  - Timing：持续。
  - Easing：ease-in-out。
  - Feeling：Playful。

## 空间与布局
- 全程一个连续 3D 世界，雪王作为移动主体把海岛、瀑布、雪地、葡萄园串成一条飞行路径；产品出现靠「推近青提→青提入杯」在同色背景中完成，空间从户外世界无缝落到手中杯子。

## 可沉淀的 Pattern 候选
1. **object-zoom-to-product（英雄物件变原料）**：把镜头推近一个英雄原料（一颗青提）让它占满画面，再让它分解/落进产品杯中变成同一堆原料。证据 16.0–19.5s。解决「原料→成品」的产品叙事，用物件形状/颜色做匹配切。
2. **character-flight-continuity（角色飞行连场）**：角色沿一个方向飞行/弹射，穿越多个 3D 场景，动势跨镜继承。证据 14.3–16.0s、31.2s。解决「角色 IP 片多场景漫游」的衔接。
- 灵感参考（不候选）：雪王表演、海岛/瀑布/葡萄园 3D 渲染、青提火箭等均为角色 IP 炫技，属不可程序化的实拍级 3D 表演。
