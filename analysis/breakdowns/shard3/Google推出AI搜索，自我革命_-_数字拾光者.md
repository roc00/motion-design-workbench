# Google推出AI搜索，自我革命（Google AI Mode，数字拾光者）

## 基础信息
- 类型：产品宣传 / UI Demo（Google AI Mode 搜索）
- 风格：极简深色 + 流体辉光渐变（liquid-gradient），大量负空间
- 适用场景：AI 产品/搜索/助手类宣传片，尤其需要表现「 AI 思考过程」与「结果浮现」的产品。
- 时长 / 大致镜头数：97.1s，cuts 仅 1 个硬切，实为一镜到底的流体形变；估算 8–10 个 UI 状态，无缝连接。

## 镜头结构
- 开场（0–24s）：深色背景，发光圆点轨道勾勒「Introducing AI Mode」，淡入 Google 搜索页，展示对比卡片，辉光勾勒「with the best of Gemini」。
- 中段（24–75s）：一句「AI Mode will let you ask」引出一条由词点连成的线，彩色波形沿线流动（AI 思考可视化），光闪后翻白，波形落成 Google 搜索栏；随后演示 dejavu、axolotl、Amtrak 列车三个真实 query 的结果流式浮现。
- 收尾（75–97s）：回到深色，「search anything」「And it's right here」，搜索栏缩成一个点，点变成 Google G 字标后淡出。
- 节奏：长镜无缝，无硬切，全程靠辉光/渐变/文字淡入连接，单段 5–10s。

## 动势（挑最典型）
- **waveform-flip-to-searchbar（28.8–34.2s）**
  - Movement：水平向（波形沿线流动）+ Z 向收束（线收细成栏）。
  - Timing：Slow Build（波形渐强）/ Fast Flash（白光 ~0.3s）/ Slow Resolve（落成栏）。
  - Easing：波形 ease-in-out，亮斑 ease-out，落栏 ease-out。
  - Feeling：Premium / Cinematic。
- **searchbar-to-G（90–95s）**
  - Movement：中心向内收缩。
  - Timing：Slow Reveal。
  - Easing：ease-in。
  - Feeling：Premium。

## 空间与布局
- 全程以一条水平发光线/波形为视觉骨架，UI 卡片在线上下淡入淡出；深↔白翻色时这条线始终存活，成为跨明暗的连续锚点。信息层级极简：一行字 + 一个 UI 块 + 辉光，负空间占 70% 以上。

## 可沉淀的 Pattern 候选
1. **waveform-flip-to-searchbar**：把「AI 正在思考」可视化成一条沿词点线流动的彩色波形，再用一道白光横扫翻转明暗，波形在新底色上收细成输入框下划线。证据 28.8–34.2s。解决「抽象 AI 处理过程→具体输入框」的衔接，把思考与输入焊成一条线。
2. **glow-flip-dark-light**：以亮度峰值（一道光/辉光膨胀）作为深色↔浅色场景的翻转点，前景一个保留下来的元素（线/点）跨明暗存活。证据 31.0–32.4s。解决「深色演示段→浅色真实 UI 段」的硬翻色。
3. **dot-line-words**：把一句话拆成词，每个词是一个圆点，点之间连线，让图形沿线流动。证据 27.0–28.8s。解决「让文案本身成为可动的骨架」，比打字机更有科技感。
4. **searchbar-collapse-to-logo**：完整搜索栏向中心缩成一个光点，点再变成品牌字标。证据 90.0–95.4s。解决「从产品 UI 收尾到品牌落版」的收束。
5. **liquid-blob-recur**：同一团辉光/圆环在段落间反复凝聚与散开，作为呼吸点。证据 52.2s、63.0s。解决「多段结果展示之间的节奏分隔」，不硬切。
- 灵感参考：真实 query 结果卡的具体内容为产品实拍式 UI，不另立机制。
