# 附录：现有体系（新卡不得重复、映射必须合法）

## 现有 30 张镜头卡（新卡必须与这些互补，不得同义重复）

### 镜头运动（camera）
- `camera.crash-zoom-punch` 急推强调 / Crash Zoom Punch — 用极短的视野推进把一个关键事实打成视觉重音。
- `camera.depth-layer-moves` 纵深分层运镜 / Depth Layer Moves — 让前中后景以不同速度移动，建立空间层级与推进感。
- `camera.space-camera-moves` 空间穿行运镜 / Space Camera Moves — 通过推、拉、横移或绕行说明对象之间的空间关系。
- `camera.overhead-camera-moves` 俯拍总览运镜 / Overhead Camera Moves — 从俯视角建立全局布局，再沿路径进入重点对象。

### 转场与衔接（transition）
- `transition.shot-transitions` 镜头交棒组合 / Shot Transitions — 按信息连续性选择硬切、暗场、焦点交棒、甩镜、遮罩或字卡。
- `transition.transition-hidden-cut` 遮挡藏切 / Transition Hidden Cut — 借主体遮挡、运动模糊或亮度峰值隐藏真实切点。
- `transition.wipe-transitions` 方向擦除 / Wipe Transitions — 用有方向的遮罩把前后画面连接成一次明确推进。
- `transition.card-flip-reveal` 卡片翻面揭示 / Card Flip Reveal — 用翻面关系表达同一对象的正反、原因结果或功能成果。
- `transition.circle-match-iris` 圆形匹配开合 / Circle Match Iris — 以圆形主体或焦点区域为匹配点完成收束与揭示。
- `transition.line-carry-transition` 线索接力转场 / Line Carry Transition — 让一条线、轨迹或边缘跨越切点，维持方向和注意力连续。

### UI 入场（ui-entrance）
- `ui-entrance.platform-hinge-rise` 平台铰链升起 / Platform Hinge Rise — 对象绕底边翻起，在固定镜头中建立证据到结论的展示关系。
- `ui-entrance.deck-deal-flyin` 发牌式飞入 / Deck Deal Flyin — 多张卡片按槽位依次飞入，快速建立集合和节奏。
- `ui-entrance.card-stack` 卡片堆叠展开 / Card Stack — 从单一堆叠状态展开多张卡，表达集合、优先级或选择。
- `ui-entrance.product-card-progressive-assemble` 产品卡渐进组装 / Product Card Progressive Assemble — 按品牌、标题、证据、行动顺序组装产品卡，控制阅读顺序。
- `ui-entrance.list-reveal` 列表渐进揭示 / List Reveal — 按阅读顺序逐项显示列表，建立扫描路径和数量感。
- `ui-entrance.morph-from-primitive` 基础形态生长 / Morph From Primitive — 从简单几何形态连续变为完整界面对象，保留来源关系。

### 交互反馈（interaction）
- `interaction.type-and-filter` 输入并筛选 / Type and Filter — 先建立输入行为，再让结果集合收敛到目标。
- `interaction.ai-stream-response` AI 流式响应 / AI Stream Response — 用短暂等待、流式文本和完成态表现请求到结果的因果链。
- `interaction.command-palette-summon` 命令面板唤起 / Command Palette Summon — 从当前上下文召出命令面板，完成输入、选择和执行。
- `interaction.input-trigger-moves` 输入触发动作 / Input Trigger Moves — 将点击、键入、拖动等触发与其视觉结果成对展示。

### 数据表达（data）
- `data.before-after-slider-scrub` 前后对比滑杆 / Before After Slider Scrub — 在同一构图中控制前后状态揭示，让差异可直接比较。
- `data.chart-live-moves` 图表动态建立 / Chart Live Moves — 按坐标、数据、重点和结论的顺序建立图表。
- `data.odometer-digit-roll` 数字滚轮 / Odometer Digit Roll — 用位数稳定的滚动变化强调从旧值到新值的数量跃迁。
- `data.timeline-travel` 时间线穿行 / Timeline Travel — 沿时间轴移动视野或游标，按因果顺序揭示节点。

### 节奏（rhythm）
- `rhythm.beat-cut-moves` 节拍硬切 / Beat Cut Moves — 把信息变化、动作峰值和声音重音对齐为清晰切点。
- `rhythm.speed-ramp-freeze` 变速与定格 / Speed Ramp Freeze — 先用速度变化压缩过程，再在关键结果上定格供阅读。
- `rhythm.montage-rhythm-moves` 蒙太奇节奏组 / Montage Rhythm Moves — 用长短镜头组合压缩多个动作，并在段末保留一个可读结果。

### 开场（opening）
- `opening.spotlight-hero-card` 聚光主角卡 / Spotlight Hero Card — 先压低环境信息，再用光、尺度和位置建立唯一主角。
- `opening.brand-ink-open` 品牌墨迹开场 / Brand Ink Open — 用品牌形态扩散或遮罩揭示建立片头识别，再迅速进入内容。

### 字体与字卡（typography）
- `typography.paper-title-card` 纸面标题卡 / Paper Title Card — 用清晰字卡承担章节切分、论点强调或时间省略。
