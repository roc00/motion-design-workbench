# WorkBuddy 第三版优化决策包

## 1. 改版结论与边界

**第三版的重点是让用户可靠地“找到效果、看懂差异、调整镜头、交给 Agent”。**

保留 Vite、GSAP、已有词典数据和深色工作台。调整页面层级、浏览状态、演示机制与输出方式；增加图表数据叙事，并将“手机屏幕展示”改为视频中的手机产品演示。

已确认的方向：

- 保留框架，重点重做体验。
- 图表服务于视频数据叙事。
- 手机场景以设备展示、模拟操作、局部放大为主。
- 保留原有 56 个词条及 ID，不删除知识内容。
- 本轮不建设视频导出器、模型调用平台、案例后台，不迁移前端框架。

旧 AE 项目值得借鉴的是“参数—预览—输出联动”和按演示类型配置控制器；不直接复制其通用代码生成逻辑。

## 3. 页面、交互与演示的实施决策

### 页面与浏览

主导航保留原四场景，增加“图表数据叙事”；“全部动效”改称“完整词典”，包含效果、原理和规则。

场景页按以下顺序组织：

1. 场景标题、一句选型建议。
2. 搜索、适配度筛选、结果数量。
3. 首选与可用效果卡片。
4. 默认收起的慎用、不推荐内容。
5. 默认收起的场景规范、提示词模板与实现说明。

具体要求：

- 首屏移除六块并列说明卡，避免读完文档才能看演示。
- 卡片默认显示该效果的真实代表帧；取消大号英文缩写封面。
- 卡片明确显示“当前场景适配度”，替代难以理解的四个彩色圆点。
- 桌面端悬停或键盘聚焦播放一次；离开停止并恢复代表帧；同时最多播放一个。
- 触屏点击进入详情，不依赖悬停获得关键信息。
- 960px 以下目录改为“目录与筛选”按钮，默认关闭；主列表使用单一纵向滚动。
- 正文至少 14px，次要信息至少 12px；触屏主要操作热区至少 44px。保留深色底，减少渐变和无含义的装饰色。

详情保持模态形式：桌面宽屏左侧舞台与播放器、右侧参数与交付；窄屏上下排列。定义、禁忌和案例放在次级区域，主操作固定为“复制制作指令”和“复制镜头配置”。

路由与状态要求：

- 保留旧 `#/effect/<id>` 链接；缺少来源上下文时进入完整词典，不默认套用文字场景。
- 新链接携带 `view`、`scenario`、`q` 和筛选条件；搜索更新不逐字增加历史记录。
- 列表上下文按视图保存滚动位置；关闭详情恢复原卡片焦点。
- 上一项、下一项沿当前可见结果顺序移动。
- 无效词条显示明确错误和返回入口。
- 搜索无结果时显示条件、清除按钮和“到完整词典搜索”；工具与触发说明页不保留无效搜索框。
- 详情内 `/` 不再聚焦背景搜索；输入框、滑杆和选择器的方向键不得触发切换词条。

### 演示可信度

每条内容新增性质标记：`effect`、`principle`、`rule`。缓动、时长、延迟归入原理；52–56 的 UX 条目归入规则。原理和规则保留演示，但不作为场景主效果推荐。

详情明确区分两种模式：

- **视频演示：**默认展示可独立播放的“进入—动作—停留—结束”；滚动、点击和指针输入转为预设时间轴。
- **交互原理：**保留真实滚动、点击、指针操作；仅显示该模式实际支持的控件。

统一控制器最低接口为：

`ready`、`play()`、`pause()`、`seek(frame)`、`reset()`、`destroy()`、`capabilities`。

实施要求：

- 卡片与详情复用相同 renderer 和 preset，仅改变尺寸及控件。
- 播放结束显示“重播”；默认保持可读终态。环境循环由用户显式开启。
- 暂停覆盖 GSAP、CSS 动画、计时器和 RAF；销毁幂等且清理全部资源。
- 任意顺序 seek 到同一帧，都产生相同结果；离散文案、随机效果不能依赖历史回调。
- 随机效果使用固定种子；演示素材本地化并等待加载完成。固定 Picsum seed 不等于可复现资产。
- 减少动态采用静态终态或短淡化，取消大幅位移、旋转和自动循环，不能仅减速。
- 修正缓动说明：曲线横轴为时间、纵轴为位移；另加同距离移动对象比较速度。
- 图片序列使用同一主体的真实连续帧或确定性绘制序列；帧数与编号一致。
- “推荐渲染层”与“当前示例能力”分别标注；不能因为写了 `deterministic` 就声称已支持视频生产。

### 手机视频场景

首批提供三个完整镜头预设，组合现有效果，不另造重复术语：

| 预设 | 镜头内容 | 默认时长 |
|---|---|---:|
| 设备入场 | 手机轻微上移显现，屏幕内容保持清晰，停留阅读 | 4 秒 |
| 操作演示 | 点击提示 → 页面或标签切换 → 结果停留 | 6 秒 |
| 屏幕讲解 | 页面滚动 → 重点区域放大 → 回到设备全貌 | 6 秒 |

设备内屏比例与输出视频画幅分开配置；默认输出 16:9，同时支持 9:16。使用本地示例界面与中性设备框，不依赖实时网站。网页交互原理保留在词典，不再占据手机视频场景的主要推荐。

## 4. 图表与 Agent 输出

### 图表首批固定为六类

借鉴 Lieflat Charts 的“数据形状—阅读目的—表现形式”选型方式，以及标题、单位、注释共同解释数据的设计。其目录中已有增长描线、柱状波次、排名变化等相关示例，可作为视觉参考。[参考目录](https://github.com/larashero3-dotcom/lieflat-charts/blob/main/catalog.md)

| ID | 回答的问题 | 默认演示编排 | 总时长 |
|---|---|---|---:|
| `chart.bar-compare` | 谁多、谁少？ | 建立坐标 → 柱条从基线增长 → 强调目标项 | 4 秒 |
| `chart.line-trend` | 如何变化？ | 坐标与时间先出现 → 折线描绘 → 标注拐点和终值 | 5 秒 |
| `chart.share` | 各部分占多少？ | 100% 横向堆叠条揭示 → 显示占比 → 强调一项 | 4 秒 |
| `chart.before-after` | 改善了多少？ | 前值 → 后值 → 差值连接与标注 | 4 秒 |
| `chart.waterfall` | 总变化由什么构成？ | 起点 → 逐项增减 → 终点与净变化 | 6 秒 |
| `chart.rank-race` | 排名怎样演变？ | 固定实体颜色，按离散时间更新数值与位置 | 8 秒 |

统一要求：

- 每个示例有结论标题、单位、时间范围、“示例数据”标记及可见最终值。
- 默认使用中性色加一个强调色，不混用多套配色。
- 数值长度、面积和计数使用不超调插值；标签不得抖动、穿插遮挡。
- 缺失值不当作 0；折线缺失处断开。占比要求非负且总和有效，不静默修改数据。
- 排名变化固定全时段尺度、实体颜色和并列排序规则，避免每帧自动缩放制造假变化。
- 每段演示保留明确阅读停留；支持任意帧定位。
- 示例数据可通过参数 JSON 编辑、校验和恢复默认；错误数据不启动播放。

首批采用已有 GSAP 配合 SVG，自行实现这六种有限图型，不增加 ECharts、Chart.js 生产依赖，也不整库导入。参考仓库当前使用 PolyForm Noncommercial 许可证，因此本版仅借鉴选型与视觉原则，不复制其模板代码。[许可证](https://github.com/larashero3-dotcom/lieflat-charts/blob/main/LICENSE)

### 数据与输出接口

保留现有词典作为知识源，增加预设数据文件，保存实际演示参数、内容、资产和时间安排。推荐范围继续属于词典，具体运行值属于预设，避免两者混写。

- 增加第五场景 `chart`；六个图表词条追加编号，原编号不变。
- 原有记录补齐第五场景适配度，不能全部机械标为可用。
- 界面、校验器和矩阵生成器均从场景注册表读取场景，去掉固定“四场景”“56 个”的展示逻辑。
- 预览、中文制作指令、结构化配置由同一份当前配置生成。
- 输出包含：效果及预设 ID、场景、内容或数据、具体参数、画布、帧率、动作与停留安排、结束状态、资源引用、约束及版本。
- 默认 1920×1080、24fps；支持 1080×1920，帧率提供 24/25/30/60。默认值作为项目约定，不绑定某个生成模型。
- 动作时长、交错、阅读停留、退场分别记录；镜头总帧数由实际时间轴计算。转场 handles 单列，不混进可见镜头时长。
- 保留既有 ShotSpec 字段形状；输出标注为“制作配置”，不宣称已完成 HyperFrames 或 Remotion 适配。
- 构建时提供可直接读取的注册表 JSON，包含 schema 版本；不新增服务端 API。

案例继续放在对应词条的 `cases` 中。界面呈现来源、预览、所属场景、值得借鉴之处及观察参数；无案例时使用简洁空态。未实际收集的案例不能以演示素材冒充。

## 5. 实施顺序与验收门槛

按以下顺序交付，前一阶段通过再进入下一阶段：

1. **浏览修复：**路由上下文、滚动恢复、焦点隔离、搜索空态、窄屏目录。
2. **演示修复：**统一控制器、真实预览、播放状态、任意帧定位、资源清理及已知错误。
3. **使用流程：**页面层级、当前参数编辑、双格式复制、手机三个预设。
4. **图表补充：**六类示例、数据验证、第五场景及生成文档。
5. **整体验收：**实际渲染、交互回归、构建和注册表验证。

必须通过的验收：

| 范围 | 验收场景 |
|---|---|
| 浏览连续性 | 滚动后打开、切换、关闭详情，原位置和筛选不丢失；刷新、分享、前进后退不改变场景结论。 |
| 键盘 | Tab 留在详情内；Esc 关闭并返回原焦点；滑杆方向键不切换词条。 |
| 响应式 | 检查 1440×900、1024×768、768×1024、390×844；无横向溢出，默认首屏出现至少一个真实预览。 |
| 演示语义 | 原 56 条逐项核对“名称—卡片—详情”；原理和规则单独统计，不伪称为视频效果。 |
| 时间控制 | 按 `0% → 100% → 0% → 50% → 10%` 跳转；同一帧画面一致，重播恢复初态。 |
| 生命周期 | 加载指示暂停后完全停止；连续开关加载、3D、弹窗演示各 20 次，无活动动画或监听器积累。 |
| 图表 | 零值、合法负值、缺失值、长中文标签、并列排名、非法占比；最终几何、标签与原数据一致。 |
| Agent 输出 | 修改文字、数值、时长或画幅后，预览与两种复制结果同步；结构化配置可以解析并恢复预览。 |
| 素材与降级 | 慢加载、加载失败、减少动态、离线条件下有明确状态，无白屏或失控循环。 |
| 工程检查 | 注册表校验、生成矩阵、生产构建通过；新增校验覆盖预设引用、参数范围、演示能力和案例结构。 |

WorkBuddy 最终需提交：修改清单、关键界面截图、逐项演示验收表、两份实际复制出的制作配置，以及明确的未完成项。**“构建通过”“56 个演示无挂载异常”不能单独作为第三版完成标准。**
