## 任务：Agent 制片动效选型体系（第一版）

### 当前假设

1. 「给 Agent 制⽤动效视频的参考」= 需要机器可读的真相源，而不是一篇长文。产出按三层做：数据源 + 规范文档 + 可交互预览站。
2. 四层结构（工具→触发→动效类型→UX 规则）来自第 1~3 篇，用于**描述**动效；四场景（文字/背景/卡片/手机）来自用户侧要求，用于**选型**。两条轴正交，都要保留。
3. 第 4 篇（混合视频制作体系）提供的是渲染层划分与 ShotSpec 合同，用于回答「这个动效该由谁实现」，不改变动效本身的定义。
4. 56 个动效里绝大多数属于确定性层或 Shader 层；真正需要生成模型的只有写实表演、世界形变等少数，且它们不在本词典范围内。

用户反馈第一版「页面视觉、交互、每一项的动态展示都不太好」，整体重做。

### 改了什么

1. **页面视觉**：卡片从「灰底文字块」改为「16:9 预览区（分组色渐变 + 字母徽标 + 场景适配度圆点）+ 信息区」；场景 tab 改为分段控件；详情从右侧抽屉改为居中大面板；引入 9 个分组色贯穿卡片、圆点、节标题。

### 修复的真实缺陷

- 设备框卡：不透明机身绘制在屏幕内容之后，盖住整块屏幕（屏幕全黑）→ 调整为 机身→裁切屏幕→刘海/边框/反光。
- 克隆成墙 / 共享形变结果卡 / 后拉全景：`zoomWrap` 内误用负的局部坐标，元素飞出画面 → 改为以锚点为中心的世界坐标。
- 中心环绕卡：`seg(.5,.9)` 漏传 `t` 产生 NaN opacity → 补 `t`。
- 文字槽卡：重复传 `font-family` 产生重复属性的非法 SVG → 去除。
