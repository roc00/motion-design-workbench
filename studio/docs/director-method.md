# 导演脚手架：从单个效果到完整表达

## 六个可填写的问题

1. 观众起初看到什么，最后理解什么？
2. 哪个主体贯穿这段：纸片、屏幕、文字、图形、路径，还是一个操作？
3. 下一状态由什么触发？可以是操作、因果、比较、信息揭示或有意剪辑。
4. 状态间保留什么：identity / position / shape / direction / color / causal meaning？
5. 什么在动，什么保持不动？分别写 subject、camera、content、edit。
6. 哪一段让观众读，哪一段让观众感受运动？时长不能统一套 2.4 秒。

## 技术与方向分别验证

闭式弹簧是可重复求值的工具，不意味着所有动作都应该弹。大字可以滑入遮罩、图形可以匀速、相机可以保持固定。三层空间、粒子、光效、镜头数量也不证明作品质量。

先以意图选择机制，再以实际画面验收：例如数字滚轮必须在进位附近才改变高位；网络需做真实旋转投影与深度排序；容器变形需检查两边的主角是否能被认作同一个对象。

## 证据口径

`browser-demo`：示意可播放。`production-adapted`：存在生产执行合同。`production-verified`：指定版本、内容、画幅的成片已验证，不自动扩展到所有参数。工作台、Skill 与注册表读取同一份 sequences 数据。新增参考要留来源链接、改写依据、实际实现与适用/避免条件。

本轮的两片分别为 2D 编辑排版/几何变形、2D 与真实 3D 网络投影混合。不将暖纸色、深色发射或任何具体品牌外观规定为通用默认风格。

## 字体边界

两支样片的 Display / Mono 已冻结；Chinese 是 Noto Sans SC 的两句示例字幕子集。修改中文文案时必须提供覆盖新字符的本地字体或重新生成子集，不能静默回退系统字体。
