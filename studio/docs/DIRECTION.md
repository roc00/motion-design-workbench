## 两个方向

| | FORMA · 收起杂念 | RELAY · 一点成网 |
|---|---|---|
| 主题 | 从许多任务中找到一个重点 | 一个信号经过连接变成网络 |
| 母题 | 纸片 → 任务卡 → 专注圆环 → 一条成果 | 点 → 波形 → 路径 → 网络 → 数字 → 品牌箭头 |
| 色板 | #eee9df / #26251f / #ed4935 | #141719 / #f0eee8 / #5878ff |
| 字体 | Archivo Black 大字、IBM Plex Mono 数据；中文仅作短说明 | 同字体，不同字号、比例与节奏 |
| 结构 | 问题 → 选择 → 放大 → 操作 → 结果 → 品牌 | 建立信号 → 路由 → 空间网络 → 数据证据 → 收束 |
| 运动 | 重量较大的排版、纸片旋转、连续几何变形、局部取景 | 路径传递、真实透视投影、深度排序、滚动数字、方向匹配 |
| 声音 | 原创短句旋律、轻打击、纸片/点击反馈 | 原创脉冲低音、切分鼓、路径 ping |

均为虚构设计研究品牌，UI 与数字为概念演示，不代表真实产品功能或商业指标。

## 时间与阅读

### FORMA

| 秒 | 画面与主角 | 交接 / 声音 |
|---|---|---|
| 0–2.4 | 完整大字 TOO MUCH. 与散落任务纸片；朱红重点在其中 | 纸片随节奏挤入，0 秒画面完整 |
| 2.4–5.4 | 散片收束为三张任务卡；目标卡从右侧选中 | 同一朱红标记保留身份，非整屏 dissolve |
| 5.4–8.4 | 目标卡扩为专注面板；背景卡向深处退开 | 主体位置与圆角连续；读字稳定区 ≥ 1 秒 |
| 8.4–11.4 | 卡上的朱红动作区收为计时圆环；25:00 | 操作反馈、圆环建立、减少并行注意点 |
| 11.4–13.2 | 圆环收成大号 ONE.，散落背景消失 | 结果揭示，与开场 TOO MUCH. 对照 |
| 13.2–15 | FORMA 品牌排版、朱红纸片标志、短中文说明 | 品牌 ≥ 1 秒稳定停留，结束不强制回到开场 |

### RELAY

| 秒 | 画面与主角 | 交接 / 声音 |
|---|---|---|
| 0–2.4 | 超大 A SIGNAL.，蓝色脉冲穿过线段 | 起音与信号启动对齐 |
| 2.4–5.4 | 脉冲沿分支路径传递，路由中心回应 | 路径末端成为下一镜的节点 |
| 5.4–8.4 | 节点构成倾斜网络平面；视点绕行 | perspective projection + z-sort；近远点尺寸不同 |
| 8.4–11.4 | 节点排成数字窗，计数落定 1,024 | 数字在遮罩内真实滚动，数据为概念示例 |
| 11.4–13.2 | 图形放大为贯穿版面的 NETWORK. | 方向与前镜一致，排版随路径推进 |
| 13.2–15 | 网络的三段折线收束为 RELAY 标志 | 主题收束、音乐终止式、品牌稳定 |

## 完成标准

两片 1920×1080 / 60fps / 15s / H.264 + AAC；工作台预览与 MP4 同一 seek 实现；支持播放、暂停、随机定位、重播、声音和制作描述复制。审阅每秒联系表、重要交接条带与 360px 读字图。旧例明确标为原理练习，新的成片与片段有来源、原理、适用条件和能力状态。Skill 构建再次执行时不得丢失新 kit 或恢复旧流程。
