# 六原则与 Slop 黑名单

## 六原则（视频不是幻灯片）

1. **一个连续世界** — 场景在同一个世界里连续演化，而不是一段段幻灯片。
2. **真动相机** — 相机始终有动机地移动（呼吸漂移 + 推进），不要固定机位。
3. **主体持续** — 主体在镜头间持续存在，而不是每个镜头重新出现。
4. **场景内文字** — 文字活在场景里，有空间关系，不是贴在屏幕正中的标签。
5. **背景不静止** — 背景始终有轻微运动（视差/漂移/纹理流动），世界不停。
6. **素材锁时间轴** — 素材/事件在时间轴上锁定，任何时刻 seek 都得到同一帧。

## Slop 黑名单（Opus 5.5 默认烂片的信号，禁止）
- 居中标题压在渐变背景上
- 所有元素统一 fade in / fade out
- 四角放标签、整帧加边框
- UI chrome 上 glow、发光
- 通用粒子爆发、无意义的装饰
- 死帧（超过 4 秒无新事件）
- 缩放 / 放大后文字发虚模糊
- 循环接缝处卡顿、跳变
